### HU-007 — Filtrar productos por categoría y marca
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-007 |
| **Título** | Filtrar productos por categoría y marca |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **RF asociados** | RF-007 |

* **Historia:** Como comprador específico, **quiero** acotar los productos visibles por categoría y marca, **para** encontrar directamente los equipamientos que se ajusten a mis necesidades.
* **Criterios de aceptación:**
    * **CA-007.1 — Combinación de filtros (Lógica AND):**
        * **Dado que** interactúo con la barra lateral de filtros,
        * **cuando** selecciono una categoría y una marca en simultáneo,
        * **entonces** el sistema concatena dinámicamente los condicionales en la base de datos y me muestra sólo los productos que cumplan estrictamente ambos criterios.
