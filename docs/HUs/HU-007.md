### HU-007 — Filtrar productos por categoría y marca
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-007 |
| **Título** | Filtrar productos por categoría y marca |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-007 |

* **Historia:** Como comprador que busca algo concreto, **quiero** aplicar filtros de categoría y marca en la vista del catálogo, **para** reducir el listado a los productos que me interesan.
* **Criterios de aceptación:**
    * **CA-007.1 — Filtro por categoría:**
        * **Dado que** estoy en el catálogo,
        * **cuando** selecciono una categoría del menú de filtros,
        * **entonces** la lista se actualiza mostrando solo productos de esa categoría mediante GET `/api/productos?categoria=X`.
    * **CA-007.2 — Filtro por marca:**
        * **Dado que** estoy en el catálogo,
        * **cuando** selecciono una marca,
        * **entonces** la lista se filtra por esa marca.
