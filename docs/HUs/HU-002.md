### HU-002 — Inicio de sesión
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-002 |
| **Título** | Inicio de sesión |
| **Módulo** | Autenticación |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-002 |

* **Historia:** Como usuario registrado, **quiero** iniciar sesión con mi correo y contraseña, **para** acceder a las funcionalidades exclusivas de mi cuenta en Jadda Sports.
* **Criterios de aceptación:**
    * **CA-002.1 — Formulario de login:**
        * **Dado que** estoy en la página de inicio de sesión (`/login`),
        * **cuando** veo el formulario,
        * **entonces** debo encontrar campos para correo electrónico y contraseña, cada uno con su icono contextual, y un botón "Iniciar sesión".
    * **CA-002.2 — Validación de campos vacíos:**
        * **Dado que** estoy completando el formulario,
        * **cuando** dejo el campo de correo o contraseña vacío y envío,
        * **entonces** debo ver un mensaje de error indicando que el campo es obligatorio.
    * **CA-002.3 — Login exitoso:**
        * **Dado que** introduzco credenciales válidas y mi cuenta está confirmada,
        * **cuando** envío el formulario,
        * **entonces** el sistema inicia mi sesión, me redirige a la página principal y muestra mi nombre de usuario en la barra de navegación.
    * **CA-002.4 — Credenciales inválidas:**
        * **Dado que** introduzco un correo o contraseña incorrectos,
        * **cuando** envío el formulario,
        * **entonces** debo ver el mensaje: "Correo o contraseña incorrectos".
    * **CA-002.5 — Cuenta no verificada:**
        * **Dado que** mi cuenta no ha sido confirmada mediante el código de verificación,
        * **cuando** intento iniciar sesión,
        * **entonces** debo ver el mensaje: "Debes verificar tu correo".
    * **CA-002.6 — Estado de carga:**
        * **Dado que** envié el formulario de inicio de sesión,
        * **cuando** la solicitud está en proceso,
        * **entonces** el botón "Iniciar sesión" debe estar deshabilitado y mostrar un indicador de carga.
    * **CA-002.7 — Enlace a registro:**
        * **Dado que** estoy en la página de inicio de sesión,
        * **cuando** no tengo una cuenta,
        * **entonces** debo encontrar un enlace "Registrarme" que me lleve a la página de registro.
    * **CA-002.8 — Enlace a recuperación de contraseña:**
        * **Dado que** olvidé mi contraseña,
        * **cuando** estoy en la página de login,
        * **entonces** debo encontrar un enlace "¿Olvidaste tu contraseña?" que me lleve a la página de recuperación.
