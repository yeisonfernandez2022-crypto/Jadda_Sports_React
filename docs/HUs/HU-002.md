### RF-002 — Inicio de sesión
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-002 |
| **Nombre** | Inicio de sesión |
| **Módulo** | Autenticación |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** El sistema debe permitir al usuario autenticarse introduciendo sus credenciales (email y contraseña). Si son válidas y la cuenta está verificada, el sistema genera y devuelve un token JSON Web Token (JWT) para la autorización de futuras solicitudes.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `email` | Texto (email) | Sí | Formato de email válido |
| `password` | Texto | Sí | No nulo, cadena de caracteres obligatoria |

* **Proceso:**
    1. El usuario introduce sus credenciales en la interfaz de inicio de sesión.
    2. El frontend comprueba la estructura básica de los campos.
    3. El backend busca el registro del usuario mediante el campo `email`.
    4. El sistema comprueba que el hash de la contraseña proporcionada coincida con el almacenado en la tabla `users` mediante comparación nativa de bcrypt.
    5. El sistema evalúa el estado del campo `is_email_verified`.
    6. Tras pasar los controles con éxito, el backend construye y firma un token JWT de acceso que contiene los claims del usuario y sus roles asignados.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Login exitoso | 200 | `{"access_token": "eyJhbG...", "token_type": "bearer"}` |
| Credenciales inválidas | 401 | Mensaje de error: `"Incorrect email or password"` |
| Email no verificado | 403 | Mensaje de error: `"Email not verified. Please verify your account first."` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/v1/auth/login` | No | Valida las credenciales y devuelve el token de sesión JWT |

* **Reglas de negocio:**
    * **RN-003:** Las cuentas asociadas a correos electrónicos no verificados (`is_email_verified = false`) tienen restringido el inicio de sesión del sistema.
