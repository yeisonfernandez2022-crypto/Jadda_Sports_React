### HU-023 — Cancelar un pedido antes de su envío
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-023 |
| **Título** | Cancelar un pedido antes de su envío |
| **Módulo** | Pedidos |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **RF asociados** | RF-023 |

* **Historia:** Como comprador arrepentido, **quiero** anular un pedido que acabo de realizar antes de que sea despachado, **para** que se libere el stock y se inicie automáticamente el proceso de reembolso de mi dinero.
* **Criterios de aceptación:**
    * **CA-023.1 — Control de estado para anulación:**
        * **Dado que** deseo cancelar una orden de compra,
        * **cuando** el estado logístico actual es `paid` o `payment_pending`,
        * **entonces** el backend aprueba la anulación de forma lógica, retorna los ítems reservados al stock general y lanza la petición de reintegro a la API bancaria.
    * **CA-023.2 — Restricción de anulación en tránsito:**
        * **Dado que** el paquete de mi pedido ya salió del centro de distribución,
        * **cuando** su estado figura en la base de datos como enviado (`shipped`),
        * **entonces** el sistema me prohíbe cancelar de forma autónoma y devuelve el error: "Order cannot be cancelled because it has already been shipped".
