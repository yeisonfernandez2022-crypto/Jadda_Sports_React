### HU-009 — Buscar productos por nombre o palabra clave
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-009 |
| **Título** | Buscar productos por nombre o palabra clave |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **RF asociados** | RF-009 |

* **Historia:** Como usuario que busca algo concreto, **quiero** escribir un término en la barra de búsqueda, **para** localizar instantáneamente un artículo sin navegar por todo el menú.
* **Criterios de aceptación:**
    * **CA-009.1 — Búsqueda insensible a mayúsculas (ILIKE):**
        * **Dado que** uso la barra de búsqueda de la cabecera,
        * **cuando** escribo una palabra clave de mínimo 3 caracteres (ej. "ZAPATILLA"),
        * **entonces** el sistema me devuelve todos los productos cuyo nombre, descripción o tags coincidan parcialmente, ignorando mayúsculas/minúsculas.
    * **CA-009.2 — Validación de longitud:**
        * **Dado que** intento buscar un término,
        * **cuando** la entrada tiene menos de 3 caracteres,
        * **entonces** el sistema bloquea la petición y muestra un error de validación 422.
