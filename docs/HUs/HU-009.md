### HU-009 — Buscar productos por nombre o palabra clave
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-009 |
| **Título** | Buscar productos por nombre o palabra clave |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-009 |

* **Historia:** Como usuario que busca algo concreto, **quiero** escribir un término en la barra de búsqueda, **para** localizar instantáneamente un artículo sin navegar por todo el menú.
* **Criterios de aceptación:**
    * **CA-009.1 — Búsqueda por palabra clave:**
        * **Dado que** uso la barra de búsqueda de la cabecera,
        * **cuando** escribo una palabra clave (ej. "zapatilla"),
        * **entonces** el sistema devuelve los productos cuyo nombre comienza con esa palabra mediante `LIKE 'palabra%'`.
    * **CA-009.2 — Búsqueda con múltiples palabras:**
        * **Dado que** busco con varias palabras,
        * **cuando** escribo "zapatilla running",
        * **entonces** se buscan productos cuyo nombre coincida con ambos términos como prefijo.
