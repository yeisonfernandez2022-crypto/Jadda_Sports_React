### HU-059 — Gestionar mis productos como vendedor
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-059 |
| **Título** | Gestionar mis productos como vendedor |
| **Módulo** | Marketplace / Vendedores |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-059 |

* **Historia:** Como vendedor, **quiero** crear y mantener mis productos en la tienda, **para** ofrecer mi catálogo y vender bajo aprobación del equipo JADDA.
* **Criterios de aceptación:**
    * **CA-059.1 — Crear pendiente:** En `/vendedor/productos/nuevo` subo imágenes, defino variantes y características; al guardar veo `PENDIENTE` y el admin es notificado.
    * **CA-059.2 — Editar con re-aprobación:** Al editar un producto `APROBADO` vuelve a `PENDIENTE` y deja de verse públicamente hasta nueva aprobación.
    * **CA-059.3 — Eliminar con restricción:** Puedo eliminar productos `PENDIENTE`/`RECHAZADO`; si intento eliminar `APROBADO` veo 400 y no se borra.
    * **CA-059.4 — Visibilidad pública:** Un producto `PENDIENTE` no aparece en catálogo ni detalle (404) hasta que el admin lo aprueba y entonces se ve con badge “Vendedor”.
