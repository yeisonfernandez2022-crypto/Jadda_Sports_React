### HU-050 — Conversarme por chat con soporte o con el vendedor
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-050 |
| **Título** | Chat multi-canal |
| **Módulo** | Comunicación / Soporte |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-050 |

* **Historia:** Como usuario de la tienda, **quiero** conversar por chat con el equipo JADDA o con el vendedor de un producto, **para** resolver dudas de envío, disponibilidad y detalles sin salir de la plataforma.
* **Criterios de aceptación:**
    * **CA-050.1 — Accesos al chat:** Desde el menú "Mis chats", desde un producto ("💬 Chatear con el vendedor" si tiene vendedor) y desde la devolución, entro a la conversación correcta.
    * **CA-050.2 — Idempotencia:** Al iniciar un chat del mismo tipo con la misma parte, se reutiliza la conversación activa existente.
    * **CA-050.3 — Mensajería:** Envío mensajes (máx. 2000 caracteres) y veo los de la otra parte como burbujas; los del sistema van centrados. Polling cada 4 s mantiene el hilo al día.
    * **CA-050.4 — Censura:** Las groserías escritas como palabras completas se guardan censuradas con asteriscos ("puta"→"****"); palabras que solo las contienen (ej. "reputación") quedan intactas.
    * **CA-050.5 — Badge de no leídos:** El acceso a chats muestra un contador rojo con mis mensajes sin leer (navbar web, menú móvil y sidebar del panel).
    * **CA-050.6 — Admin responde:** Los administradores ven todos los hilos en `/admin/chats` (con filtro "solo escaladas"), responden los tickets de soporte y NO pueden abrir tickets propios.
