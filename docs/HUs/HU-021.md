### HU-021 — Generar una factura o comprobante digital
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-021 |
| **Título** | Generar una factura o comprobante digital |
| **Módulo** | Pedidos / Facturación |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **RF asociados** | RF-021 |

* **Historia:** Como cliente formal, **quiero** descargar la factura legal de mi compra en formato PDF, **para** archivarla como soporte de mis gastos personales o contables.
* **Criterios de aceptación:**
    * **CA-021.1 — Descarga de PDF binario:**
        * **Dado que** tengo un pedido con estado pagado (`paid`),
        * **cuando** hago clic en el botón de descarga del comprobante dentro de mi panel,
        * **entonces** el backend compila de forma dinámica los datos fiscales y me retorna un flujo de datos binarios (Stream) con formato `application/pdf`.
