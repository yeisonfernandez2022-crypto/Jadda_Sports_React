### HU-012 — Mostrar productos relacionados o recomendados
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-012 |
| **Título** | Mostrar productos relacionados o recomendados |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Baja |
| **Estado** | Implementada |
| **RF asociados** | RF-012 |

* **Historia:** Como cliente indeciso, **quiero** ver sugerencias de artículos similares al que estoy revisando, **para** descubrir alternativas de compra de manera rápida.
* **Criterios de aceptación:**
    * **CA-012.1 — Productos relacionados:**
        * **Dado que** estoy en la página de detalle de un producto,
        * **cuando** veo la sección de productos relacionados,
        * **entonces** se muestran hasta 4 productos de la misma categoría obtenidos desde GET `/api/productos/relacionados/:id`.
    * **CA-012.2 — Fallback a otras categorías:**
        * **Dado que** hay menos de 4 productos en la misma categoría,
        * **cuando** se cargan los relacionados,
        * **entonces** el sistema completa con productos de otras categorías.
