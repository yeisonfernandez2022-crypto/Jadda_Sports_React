### HU-012 — Mostrar productos relacionados o recomendados
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-012 |
| **Título** | Mostrar productos relacionados o recomendados |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Baja |
| **Estado** | Por implementar |
| **RF asociados** | RF-012 |

* **Historia:** Como cliente indeciso, **quiero** ver sugerencias de artículos similares al que estoy revisando, **para** descubrir alternativas de compra de manera rápida.
* **Criterios de aceptación:**
    * **CA-012.1 — Carrusel acotado (Límite 4):**
        * **Dado que** estoy al final de la página detallada de un producto,
        * **cuando** el bloque de recomendaciones se carga,
        * **entonces** consulta la base de datos buscando un máximo de 4 artículos bajo la misma categoría o marca, ordenados por volumen de ventas y omitiendo el artículo actual.
