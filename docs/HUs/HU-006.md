### HU-006 — Mostrar el catálogo de productos disponibles
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-006 |
| **Título** | Mostrar el catálogo de productos disponibles |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **RF asociados** | RF-006 |

* **Historia:** Como cliente de la tienda, **quiero** visualizar un catálogo paginado con todos los productos disponibles, **para** explorar los artículos deportivos de forma fluida.
* **Criterios de aceptación:**
    * **CA-006.1 — Paginación desde servidor:**
        * **Dado que** ingreso a la tienda o navego por el catálogo,
        * **cuando** el sistema carga la interfaz,
        * **entonces** realiza una consulta limitada (`LIMIT` / `OFFSET`) mostrando únicamente artículos con `is_active = true` y devolviendo el total general de ítems.
