### HU-006 — Mostrar el catálogo de productos disponibles
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-006 |
| **Título** | Mostrar el catálogo de productos disponibles |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-006 |

* **Historia:** Como cliente de la tienda, **quiero** visualizar un catálogo paginado con todos los productos disponibles, **para** explorar los artículos deportivos de forma fluida.
* **Criterios de aceptación:**
    * **CA-006.1 — Visualización del catálogo:**
        * **Dado que** entro a la tienda o navego al catálogo,
        * **cuando** la página se carga,
        * **entonces** veo una lista de productos con nombre, precio, imagen y marca obtenidos desde GET `/api/productos`.
