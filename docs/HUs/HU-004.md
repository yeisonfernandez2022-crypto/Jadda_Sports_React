### HU-004 — Actualización de datos personales
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-004 |
| **Título** | Actualización de datos personales |
| **Módulo** | Perfil de usuario |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-004 |

* **Historia:** Como cliente registrado, **quiero** modificar la información de mi perfil (nombre, teléfono, dirección), **para** mantener mis datos de contacto actualizados para futuros despachos.
* **Criterios de aceptación:**
    * **CA-004.1 — Ver perfil:**
        * **Dado que** inicié sesión y accedo a mi perfil,
        * **cuando** se carga la página,
        * **entonces** veo mis datos personales (nombre, apellido, email, teléfono) obtenidos mediante GET `/api/auth/perfil`.
    * **CA-004.2 — Actualizar datos:**
        * **Dado que** estoy en mi perfil,
        * **cuando** edito los campos permitidos (nombre, apellido, teléfono, etc.) y guardo,
        * **entonces** el sistema actualiza mi información mediante PUT `/api/auth/perfil`.
    * **CA-004.3 — Rechazo por falta de sesión:**
        * **Dado que** no estoy autenticado,
        * **cuando** intento acceder al perfil,
        * **entonces** el backend responde: "No hay sesión activa en el servidor".
