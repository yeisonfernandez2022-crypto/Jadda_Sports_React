### HU-004 — Actualización de datos personales
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-004 |
| **Título** | Actualización de datos personales |
| **Módulo** | Perfil de usuario |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **RF asociados** | RF-004 |

* **Historia:** Como cliente registrado, **quiero** modificar la información de mi perfil (nombre, teléfono, dirección), **para** mantener mis datos de contacto actualizados para futuros despachos.
* **Criterios de aceptación:**
    * **CA-004.1 — Guardado exitoso de datos básicos:**
        * **Dado que** inicié sesión y estoy en el panel de configuración de perfil,
        * **cuando** edito campos editables permitidos y guardo los cambios,
        * **entonces** el sistema actualiza la base de datos de usuarios y muestra un mensaje de éxito.
    * **CA-004.2 — Rechazo por falta de sesión:**
        * **Dado que** expiró mi token de sesión o no estoy autenticado,
        * **cuando** intento enviar una petición de cambio al endpoint del perfil,
        * **entonces** el backend devuelve un código de error de autenticación: "Could not validate credentials".
