### HU-029 — Actualizar el inventario de manera detallada
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-029 |
| **Título** | Actualizar el inventario de manera detallada |
| **Módulo** | Panel de administración / Inventario |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-029 |

* **Historia:** Como encargado de almacén, **quiero** ajustar manualmente las existencias físicas de las variantes de productos, **para** corregir inconsistencias del stock o asentar nuevas entradas de mercancía.
* **Criterios de aceptación:**
    * **CA-029.1 — Actualizar stock de variante:**
        * **Dado que** estoy editando un producto en el panel admin (`/admin/editar/:id`),
        * **cuando** modifico el campo STOCK de una variante específica (talla/color) y guardo,
        * **entonces** el backend actualiza el registro en `PRODUCTO_VARIANTES` mediante `PUT /api/productos/:id/variantes/:idVariante`.
    * **CA-029.2 — Movimiento registrado:**
        * **Dado que** se actualiza el stock de una variante,
        * **cuando** el cambio se efectúa,
        * **entonces** también se registra el movimiento en la tabla `MOVIMIENTOS_STOCK` para auditoría.
