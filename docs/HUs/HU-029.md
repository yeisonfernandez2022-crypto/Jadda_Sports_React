### HU-029 — Actualizar el inventario de manera detallada
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-029 |
| **Título** | Actualizar el inventario de manera detallada |
| **Módulo** | Panel de administración / Inventario |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **RF asociados** | RF-029 |

* **Historia:** Como encargado de almacén, **quiero** ajustar manualmente las existencias físicas de las variantes de productos, **para** corregir inconsistencias del stock o asentar nuevas entradas de mercancía.
* **Criterios de aceptación:**
    * **CA-029.1 — Transacción segura y log de auditoría:**
        * **Dado que** registro un ajuste manual de stock (positivo o negativo) para un SKU variante,
        * **cuando** el backend procesa la petición,
        * **entonces** abre una transacción de base de datos, actualiza la columna `quantity_available` e inserta obligatoriamente una fila de auditoría con la estampa de tiempo, cantidad y el ID del administrador responsable.
