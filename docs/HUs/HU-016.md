### HU-016 — Aplicar cupones de descuento
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-016 |
| **Título** | Aplicar cupones de descuento |
| **Módulo** | Carrito de compras / Promociones |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **RF asociados** | RF-016 |

* **Historia:** Como cliente que posee una promoción, **quiero** ingresar un código alfanumérico en el resumen del pedido, **para** obtener un descuento especial sobre el valor total de mi compra.
* **Criterios de aceptación:**
    * **CA-016.1 — Validación de restricciones del cupón:**
        * **Dado que** escribo un código en el cuadro promocional,
        * **cuando** el cupón está vencido, inactivo o mi carrito no supera el monto mínimo de compra exigido,
        * **entonces** el sistema rechaza la aplicación y notifica: "Coupon code is invalid, expired, or condition unmet".
    * **CA-016.2 — Restricción de acumulación:**
        * **Dado que** ya tengo un cupón de descuento activo en el checkout actual,
        * **cuando** intento ingresar un segundo código alfanumérico,
        * **entonces** el sistema me impide procesarlo de acuerdo a la regla de no acumulación.
