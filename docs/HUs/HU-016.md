### HU-016 — Aplicar cupones de descuento
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-016 |
| **Título** | Aplicar cupones de descuento |
| **Módulo** | Carrito de compras / Promociones |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-016 |

* **Historia:** Como cliente que posee una promoción, **quiero** ingresar un código alfanumérico en el resumen del pedido, **para** obtener un descuento especial sobre el valor total de mi compra.
* **Criterios de aceptación:**
    * **CA-016.1 — Validación del cupón:**
        * **Dado que** ingreso un código promocional en el checkout,
        * **cuando** envío el código,
        * **entonces** el backend consulta la tabla `DESCUENTOS` y si el código es válido y está vigente, devuelve el porcentaje de descuento a aplicar.
    * **CA-016.2 — Cupón inválido o vencido:**
        * **Dado que** ingreso un cupón inválido, vencido o que no cumple las condiciones,
        * **cuando** se valida,
        * **entonces** el sistema responde con el mensaje: "Cupón inválido o vencido".
    * **CA-016.3 — Sin acumulación:**
        * **Dado que** ya tengo un cupón activo,
        * **cuando** intento ingresar un segundo código,
        * **entonces** el sistema rechaza la aplicación (no se permite acumulación de múltiples cupones).
