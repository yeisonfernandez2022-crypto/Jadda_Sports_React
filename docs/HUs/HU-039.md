### HU-039 — Contactar al soporte desde la plataforma
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-039 |
| **Título** | Contactar al soporte desde la plataforma |
| **Módulo** | Soporte técnico / Tickets |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **RF asociados** | RF-039 |

* **Historia:** Como cliente que experimenta un problema, **quiero** enviar un mensaje detallado a través de un formulario de soporte técnico, **para** abrir un ticket formal de asistencia y que el equipo resuelva mi inconveniente.
* **Criterios de aceptación:**
    * **CA-039.1 — Apertura exitosa de tickets numerados:**
        * **Dado que** accedo al formulario de contacto e introduzco un asunto y cuerpo de mensaje descriptivo,
        * **cuando** envío la solicitud de asistencia técnica,
        * **entonces** el sistema inserta el registro en la tabla `support_tickets` asignando mi ID de usuario, estableciendo el estado inicial como `open` y devolviéndome un identificador numérico secuencial como confirmación.
