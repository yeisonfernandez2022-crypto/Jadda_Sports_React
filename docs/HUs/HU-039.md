### HU-039 — Contactar al soporte desde la plataforma
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-039 |
| **Título** | Contactar al soporte desde la plataforma |
| **Módulo** | Soporte técnico / Tickets |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-039 |

* **Historia:** Como cliente que experimenta un problema, **quiero** enviar un mensaje detallado a través de un formulario de soporte técnico, **para** abrir un ticket formal de asistencia y que el equipo resuelva mi inconveniente.
* **Criterios de aceptación:**
    * **CA-039.1 — Formulario PQR:**
        * **Dado que** estoy autenticado y accedo a la página `/pqr`,
        * **cuando** veo el formulario,
        * **entonces** debo encontrar campos para tipo (Petición, Queja, Reclamo, Sugerencia), asunto, descripción y número de pedido (opcional).
    * **CA-039.2 — Envío de PQR:**
        * **Dado que** completo todos los campos obligatorios del formulario,
        * **cuando** envío la solicitud,
        * **entonces** el backend guarda el registro en la tabla `PQR` con estado inicial `PENDIENTE` mediante `POST /api/pqr` y muestra el mensaje "PQR creada correctamente".
