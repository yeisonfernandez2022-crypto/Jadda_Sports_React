### HU-048 — Enviar mensaje de contacto al soporte
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-048 |
| **Título** | Formulario de contacto |
| **Módulo** | Soporte técnico |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-048 |

* **Historia:** Como visitante o cliente, **quiero** enviar consultas o sugerencias a través del formulario de contacto, **para** comunicarme con el equipo de JADDA SPORTS sin necesidad de iniciar sesión.
* **Criterios de aceptación:**
    * **CA-048.1 — Formulario de contacto:**
        * **Dado que** accedo a la página `/contacto`,
        * **cuando** veo el formulario,
        * **entonces** debo encontrar campos para nombre, correo y mensaje.
    * **CA-048.2 — Envío del mensaje:**
        * **Dado que** completo los campos obligatorios correctamente,
        * **cuando** envío el formulario,
        * **entonces** el sistema transmite el mensaje por correo al equipo con `POST /api/contacto` y muestra un mensaje de éxito.
    * **CA-048.3 — Validación de campos:**
        * **Dado que** dejo campos obligatorios vacíos o ingreso un correo inválido,
        * **cuando** envío el formulario,
        * **entonces** el sistema responde 400 con un mensaje descriptivo.
    * **CA-048.4 — Límite de envíos:**
        * **Dado que** excedo el número de envíos permitidos por IP,
        * **cuando** intento enviar otro mensaje,
        * **entonces** el sistema responde 429 indicando el límite de peticiones.
    * **CA-048.5 — Error de envío:**
        * **Dado que** el servidor de correo falla,
        * **cuando** envío el formulario,
        * **entonces** el sistema responde 500 con un mensaje genérico "Error al enviar el mensaje. Intenta de nuevo." sin exponer detalles técnicos.
