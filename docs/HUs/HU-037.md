### HU-037 — Compartir productos en redes sociales
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-037 |
| **Título** | Compartir productos en redes sociales |
| **Módulo** | Interacción de usuarios |
| **Prioridad** | Baja |
| **Estado** | Por implementar |
| **RF asociados** | RF-037 |

* **Historia:** Como usuario activo de redes sociales, **quiero** compartir enlaces de los productos de la tienda en mis perfiles (Facebook, X, WhatsApp), **para** recomendárselos a mis amigos mostrando correctamente su foto y precio.
* **Criterios de aceptación:**
    * **CA-037.1 — Inyección de etiquetas Open Graph:**
        * **Dado que** comparto una URL detallada de un producto de la tienda,
        * **cuando** el servidor responde a los scrapers de las redes sociales,
        * **entonces** inyecta dinámicamente las metaetiquetas de cabecera (`og:title`, `og:image`, `og:price`) para asegurar que la vista previa visual del artículo se despliegue con total fidelidad en la red externa.
