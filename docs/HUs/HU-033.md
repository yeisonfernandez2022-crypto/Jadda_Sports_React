### HU-033 — Gestionar devoluciones de productos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-033 |
| **Título** | Gestionar devoluciones de productos |
| **Módulo** | Panel de administración / Postventa |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-033 |

* **Historia:** Como encargado de atención postventa, **quiero** evaluar y cambiar el estado de las solicitudes de devolución de los clientes, **para** autorizar de forma centralizada la devolución del dinero y el reingreso automático de los artículos al stock disponible.
* **Criterios de aceptación:**
    * **CA-033.1 — Solicitud del cliente:**
        * **Dado que** tengo un pedido COMPLETADO con productos,
        * **cuando** pulso "Devolver" en un producto e indico cantidad y motivo,
        * **entonces** se crea la solicitud con estado SOLICITADA y queda visible para el administrador; la cantidad no puede superar la comprada (menos lo ya solicitado).
    * **CA-033.2 — Procesamiento de reembolso y reversión de inventario:**
        * **Dado que** apruebo formalmente una solicitud de devolución abierta,
        * **cuando** el backend procesa el cambio de estado,
        * **entonces** las existencias se actualizan sumando los artículos devueltos al stock de la variante, la solicitud queda APROBADA y el cliente recibe una notificación in-app; el reembolso se gestiona por el método de pago original.
    * **CA-033.3 — Rechazo:**
        * **Dado que** rechazo una solicitud abierta,
        * **cuando** el backend procesa el cambio de estado,
        * **entonces** la solicitud queda RECHAZADA sin reingreso de stock y el cliente recibe una notificación in-app.
