### HU-033 — Gestionar devoluciones de productos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-033 |
| **Título** | Gestionar devoluciones de productos |
| **Módulo** | Panel de administración / Postventa |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **RF asociados** | RF-033 |

* **Historia:** Como encargado de atención postventa, **quiero** evaluar y cambiar el estado de las solicitudes de reembolso de los clientes, **para** autorizar de forma centralizada la devolución del dinero y el reingreso automático de los artículos al stock disponible.
* **Criterios de aceptación:**
    * **CA-033.1 — Procesamiento de reembolso y reversión de inventario:**
        * **Dado que** apruebo formalmente una solicitud de devolución abierta,
        * **cuando** el backend procesa el cambio de estado,
        * **entonces** se conecta con la pasarela de pagos para reintegrar los fondos y actualiza las existencias sumando los artículos devueltos al SKU variante.
