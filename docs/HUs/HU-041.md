### HU-041 — Generar y llevar un plan de entrenamiento
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-041 |
| **Título** | Plan de entrenamiento |
| **Módulo** | Fidelización / Planes |
| **Prioridad** | Baja |
| **Estado** | Implementada |
| **RF asociados** | RF-041 |

* **Historia:** Como usuario autenticado, **quiero** generar un plan de entrenamiento personalizado y marcar los días que completo, **para** dar seguimiento a mi progreso físico y mantenerme motivado.
* **Criterios de aceptación:**
    * **CA-041.1 — Consultar mis planes:**
        * **Dado que** estoy autenticado y accedo a la sección de planes,
        * **cuando** consulto mis planes,
        * **entonces** el sistema me muestra la lista de planes mediante `GET /api/planes`, con los días completados de cada uno.
    * **CA-041.2 — Generar plan:**
        * **Dado que** aún no tengo un plan de entrenamiento,
        * **cuando** solicito generar uno,
        * **entonces** el sistema crea un plan con `POST /api/planes/generar` y lo muestra con `dias_completados = 0`.
    * **CA-041.3 — Marcar día completado:**
        * **Dado que** completé un día de mi plan,
        * **cuando** marco el día como completado,
        * **entonces** el sistema registra el avance con `POST /api/planes/marcar-dia/:id_plan` y actualiza `dias_completados`.
    * **CA-041.4 — Persistencia del progreso:**
        * **Dado que** marcó días completados en una sesión,
        * **cuando** cierro sesión o vuelvo más tarde,
        * **entonces** mi progreso se mantiene (persistido en `backend/data/planes-progreso.json`) y se restaura al consultar mis planes.
