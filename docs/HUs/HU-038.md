### HU-038 — Recomendaciones basadas en compras previas
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-038 |
| **Título** | Recomendaciones basadas en compras previas |
| **Módulo** | Analítica / Fidelización |
| **Prioridad** | Baja |
| **Estado** | Por implementar |
| **RF asociados** | RF-038 |

* **Historia:** Como cliente recurrente, **quiero** ver sugerencias personalizadas en la página de inicio en base a las categorías que compré antes, **para** descubrir novedades acordes a mis deportes preferidos de forma directa.
* **Criterios de aceptación:**
    * **CA-038.1 — Algoritmo de sugerencia por categorías:**
        * **Dado que** inicio sesión y accedo a la vista de portada de la tienda,
        * **cuando** el sistema carga el bloque de recomendaciones personalizadas,
        * **entonces** analiza las categorías asociadas a mis pedidos cerrados anteriores y me despliega un conjunto adaptado de artículos complementarios sugeridos.
