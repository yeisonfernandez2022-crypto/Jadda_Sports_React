### HU-027 — Gestionar las categorías de productos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-027 |
| **Título** | Gestionar las categorías de productos |
| **Módulo** | Panel de administración |
| **Prioridad** | Media |
| **Estado** | Parcial |
| **RF asociados** | RF-027 |

* **Historia:** Como usuario de la tienda, **quiero** ver las categorías disponibles para filtrar productos, **para** encontrar más fácilmente los artículos deportivos que me interesan.
* **Criterios de aceptación:**
    * **CA-027.1 — Visualización de categorías:**
        * **Dado que** estoy navegando el catálogo,
        * **cuando** abro los filtros de categoría,
        * **entonces** veo una lista con todas las categorías disponibles obtenidas desde `GET /api/productos/categorias`.
    * **CA-027.2 — CRUD de categorías (pendiente):**
        * **Dado que** soy administrador,
        * **cuando** intento crear, editar o eliminar categorías,
        * **entonces** la funcionalidad aún no está implementada en el panel de administración.
