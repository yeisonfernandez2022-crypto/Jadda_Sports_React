### HU-027 — Gestionar las categorías de productos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-027 |
| **Título** | Gestionar las categorías de productos |
| **Módulo** | Panel de administración |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-027 |

* **Historia:** Como administrador de la tienda, **quiero** crear, editar y eliminar las categorías de productos desde el panel administrativo, **para** mantener organizado el catálogo y que los clientes encuentren fácilmente los artículos que les interesan.
* **Criterios de aceptación:**
    * **CA-027.1 — Visualización de categorías:**
        * **Dado que** estoy navegando el catálogo,
        * **cuando** abro los filtros de categoría,
        * **entonces** veo una lista con todas las categorías disponibles obtenidas desde `GET /api/productos/categorias`.
    * **CA-027.2 — Crear categoría:**
        * **Dado que** soy administrador en `/admin/categorias`,
        * **cuando** ingreso un nombre único (3-100 caracteres) y una descripción opcional y guardo,
        * **entonces** la categoría aparece en el listado y en los filtros del catálogo; un nombre duplicado o demasiado corto muestra un error.
    * **CA-027.3 — Editar categoría:**
        * **Dado que** soy administrador,
        * **cuando** modifico el nombre o la descripción de una categoría,
        * **entonces** los cambios se reflejan en el catálogo; el nombre no puede duplicar otra categoría.
    * **CA-027.4 — Eliminar categoría:**
        * **Dado que** soy administrador,
        * **cuando** intento eliminar una categoría sin productos asociados,
        * **entonces** se elimina; si tiene productos, el sistema lo impide mostrando el conteo.
