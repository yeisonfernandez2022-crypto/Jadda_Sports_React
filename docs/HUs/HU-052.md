### HU-052 — Gestionar el envío de mis ventas como vendedor
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-052 |
| **Título** | Gestión de ventas del vendedor |
| **Módulo** | Marketplace / Ventas |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-052 |

* **Historia:** Como vendedor, **quiero** actualizar el estado de envío de los pedidos que incluyen mis productos, **para** informar al cliente y coordinar la entrega sin depender del administrador.
* **Criterios de aceptación:**
    * **CA-052.1 — Mis ventas con envío:** En "Mis ventas" veo cada pedido con su stepper de 5 pasos, dirección/teléfono del cliente y estado de venta.
    * **CA-052.2 — Avanzar estado:** Puedo marcar cualquier paso (click directo o botón "Avanzar"), cancelar el envío y cambiar el estado de la venta; el cliente recibe notificación de cada cambio.
    * **CA-052.3 — Entregado registra fecha:** Marcar ENTREGADO guarda `FECHA_ENTREGA`.
    * **CA-052.4 — Propiedad:** Intentar gestionar una venta sin productos míos devuelve 403.
    * **CA-052.5 — Admin lectura en terceros:** En Órdenes, las ventas con productos de vendedores muestran chip morado con la empresa, stepper/select deshabilitados y sin botones de avance/cancelación; la factura PDF sigue disponible. Las ventas 100% JADDA siguen 100% interactivas.
