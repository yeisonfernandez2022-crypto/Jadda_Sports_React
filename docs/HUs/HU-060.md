### HU-060 — Conocer el costo de envío antes de pagar
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-060 |
| **Título** | Costo de envío por ubicación |
| **Módulo** | Checkout / Logística |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-060 |

* **Historia:** Como comprador, **quiero** ver el costo de envío según mi departamento y ciudad y saber cuánto me falta para envío gratis, **para** decidir mi compra con transparencia.
* **Criterios de aceptación:**
    * **CA-060.1 — Cálculo dinámico:** Al elegir departamento/ciudad en el checkout veo el costo actualizado (ej. Bogotá 10k, Medellín 12k) sin recargar la página.
    * **CA-060.2 — Barra de envío gratis:** Veo “Te faltan $X para envío gratis” con barra de progreso; al superar $800.000 veo “¡Tienes envío gratis!” en verde.
    * **CA-060.3 — Gratis automático:** Si mi carrito supera $800.000 el checkout muestra envío $0 y lo guarda así en la factura y el correo.
