### HU-061 — Radicar una PQR
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-061 |
| **Título** | Radicar PQR |
| **Módulo** | Soporte / PQR |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-061 |

* **Historia:** Como cliente, **quiero** radicar una petición, queja o reclamo con mi número de pedido, **para** que el equipo JADDA me dé respuesta y seguimiento.
* **Criterios de aceptación:**
    * **CA-061.1 — Formulario PQR accesible:** En `/pqr` (requiere login) veo formulario con tipo, asunto, descripción y número de pedido opcional; si no estoy logueado me pide iniciar sesión.
    * **CA-061.2 — Radicado exitoso:** Al enviar con datos válidos veo confirmación “PQR radicada con éxito” y se guarda con estado `PENDIENTE`.
    * **CA-061.3 — Validación:** Si dejo asunto/descripción vacíos o muy cortos veo mensajes de validación y no se envía.
