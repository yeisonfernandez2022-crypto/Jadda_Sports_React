### HU-024 — Consultar su historial de compras
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-024 |
| **Título** | Consultar su historial de compras |
| **Módulo** | Pedidos |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **RF asociados** | RF-024 |

* **Historia:** Como cliente frecuente, **quiero** tener acceso a una lista cronológica con todas mis compras pasadas, **para** recordar los modelos deportivos que adquirí anteriormente y verificar sus costos.
* **Criterios de aceptación:**
    * **CA-024.1 — Listado retrospectivo paginado:**
        * **Dado que** abro la sección de "Mis compras",
        * **cuando** el frontend invoca al servicio correspondiente adjuntando mi sesión,
        * **entonces** el backend devuelve ordenadamente el histórico completo de facturas y estados del cliente de manera descendente.
