### HU-024 — Consultar su historial de compras
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-024 |
| **Título** | Consultar su historial de compras |
| **Módulo** | Pedidos |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-024 |

* **Historia:** Como cliente frecuente, **quiero** tener acceso a una lista cronológica con todas mis compras pasadas, **para** recordar los modelos deportivos que adquirí anteriormente y verificar sus costos.
* **Criterios de aceptación:**
    * **CA-024.1 — Historial cronológico:**
        * **Dado que** abro la sección "Mis Compras" en `/perfil/compras`,
        * **cuando** el frontend hace GET a `/api/compras`,
        * **entonces** el backend devuelve el historial completo de compras del usuario autenticado desde la tabla `VENTAS`, ordenado de la más reciente a la más antigua, incluyendo fechas, totales, estados y productos.
