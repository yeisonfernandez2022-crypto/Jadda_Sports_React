### HU-049 — Recordar y mostrar el historial de navegación del usuario
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-049 |
| **Título** | Historial de navegación |
| **Módulo** | Usuario / Personalización |
| **Prioridad** | Baja |
| **Estado** | Implementada |
| **RF asociados** | RF-049 |

* **Historia:** Como usuario (con o sin sesión), **quiero** ver en la portada los productos que he visitado recientemente, **para** retomar fácilmente mis búsquedas y compras pendientes.
* **Criterios de aceptación:**
    * **CA-049.1 — Registro de visita:**
        * **Dado que** visito la página de detalle de un producto,
        * **cuando** la página carga,
        * **entonces** el sistema guarda la visita (localStorage siempre; `POST /api/historial` si tengo sesión) con los datos `ID_PRODUCTO`, `ID_DESCUENTO`, `STOCK` e `ID_VARIANTE_POR_DEFECTO`.
    * **CA-049.2 — Sección "Recientemente vistos":**
        * **Dado que** he visitado productos,
        * **cuando** abro la portada,
        * **entonces** veo la sección "Recientemente vistos" con las tarjetas de los productos visitados, obtenidas con `GET /api/historial` (sesión) o desde localStorage (sin sesión).
    * **CA-049.3 — Datos completos en las tarjetas:**
        * **Dado que** veo un producto recientemente visto,
        * **cuando** la tarjeta se renderiza,
        * **entonces** muestra precio con descuento si aplica y badge de stock ("AGOTADO" / "Solo quedan X").
    * **CA-049.4 — Agregar al carrito desde el historial:**
        * **Dado que** veo un producto recientemente visto,
        * **cuando** hago clic en agregar al carrito,
        * **entonces** el producto se agrega al carrito con la variante por defecto registrada.
