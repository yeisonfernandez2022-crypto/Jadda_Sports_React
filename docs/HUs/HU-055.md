### HU-055 — Entender que los vendedores no compran
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-055 |
| **Título** | Vendedores no pueden comprar |
| **Módulo** | Marketplace / Reglas |
| **Prioridad** | Baja |
| **Estado** | Implementada |
| **RF asociados** | RF-055 |

* **Historia:** Como visitante de la tienda con cuenta de vendedor, **quiero** entender claramente que no puedo comprar con esa cuenta, **para** no confundirme al usar la plataforma.
* **Criterios de aceptación:**
    * **CA-055.1 — Botón deshabilitado con explicación:** Los botones de agregar al carrito se ven atenuados; al pasar el cursor dicen "Los vendedores no pueden comprar en la tienda".
    * **CA-055.2 — Mensaje al hacer click:** Hacer click muestra el mensaje explicativo en lugar de agregar productos.
    * **CA-055.3 — Refuerzo backend:** Aunque se intente por API, agregar al carrito o pagar con cuenta de vendedor devuelve 403 con el mensaje explicativo (también en móvil).
