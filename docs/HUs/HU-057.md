### HU-057 — Gestionar solicitudes de vendedores
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-057 |
| **Título** | Gestionar solicitudes de vendedores |
| **Módulo** | Administración / Vendedores |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-057 |

* **Historia:** Como administrador, **quiero** revisar y decidir sobre cada solicitud para ser vendedor, **para** habilitar vendedores confiables y notificar a los solicitantes con claridad.
* **Criterios de aceptación:**
    * **CA-057.1 — Bandeja con estados:** En `/admin/vendedores` veo tabla con empresa, solicitante (“Sin cuenta” si fue pública), ubicación, fecha y estado con filtros `Todas/Pendientes/Aprobadas/Rechazadas`; `Pendientes` arriba.
    * **CA-057.2 — Aprobar crea vendedor:** Al aprobar una pendiente se crea el usuario vendedor, se envían credenciales temporales por correo y el solicitante ve “Cuenta activa” con su `EMAIL_VENDEDOR`.
    * **CA-057.3 — Rechazo con motivo obligatorio:** Al rechazar debo escribir motivo (5-500); si intento sin motivo veo 400 y no se rechaza; el solicitante ve el motivo y puede reenviar.
    * **CA-057.4 — Cambio de contraseña forzado:** El vendedor al iniciar con la temporal ve Swal obligatorio para cambiarla; si cancela se cierra la sesión.
