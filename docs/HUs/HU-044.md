### HU-044 — Iniciar sesión con redes sociales (Google y Facebook)
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-044 |
| **Título** | Login social |
| **Módulo** | Autenticación |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-044 |

* **Historia:** Como usuario nuevo o existente, **quiero** iniciar sesión con mi cuenta de Google o Facebook, **para** acceder a la plataforma sin tener que recordar otra contraseña.
* **Criterios de aceptación:**
    * **CA-044.1 — Botón de Google:**
        * **Dado que** estoy en el modal de inicio de sesión,
        * **cuando** hago clic en el botón "Google",
        * **entonces** se abre el flujo OAuth (`GET /api/auth/google`) y, al autenticarme, quedo con sesión iniciada.
    * **CA-044.2 — Botón de Facebook:**
        * **Dado que** estoy en el modal de inicio de sesión,
        * **cuando** hago clic en el botón "Facebook",
        * **entonces** se abre el flujo OAuth (`GET /api/auth/facebook`) y, al autenticarme, quedo con sesión iniciada.
    * **CA-044.3 — Creación automática de cuenta:**
        * **Dado que** me autentico por primera vez con una red social,
        * **cuando** el proveedor devuelve mis datos,
        * **entonces** el sistema crea mi cuenta automáticamente con rol cliente y confirmada, y me muestra la sesión activa.
    * **CA-044.4 — Facebook sin email:**
        * **Dado que** Facebook no me devuelve un correo electrónico,
        * **cuando** intento autenticarme,
        * **entonces** el sistema muestra el error "Facebook no proporcionó email" y no crea la cuenta.
    * **CA-044.5 — Cierre del popup con sesión:**
        * **Dado que** completé la autenticación en el popup,
        * **cuando** el popup se cierra,
        * **entonces** la página principal procesa el resultado (`OAuthPopupCallback`) y actualiza mi perfil con los datos recibidos.
