### HU-036 — Crear y gestionar una lista de deseos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-036 |
| **Título** | Crear y gestionar una lista de deseos |
| **Módulo** | Interacción de usuarios |
| **Prioridad** | Baja |
| **Estado** | Por implementar |
| **RF asociados** | RF-036 |

* **Historia:** Como cliente registrado, **quiero** guardar productos en una lista de deseos personalizada, **para** realizar el seguimiento de mis artículos favoritos y poder agregarlos a mi carrito de compras más adelante.
* **Criterios de aceptación:**
    * **CA-036.1 — Persistencia de la Wishlist:**
        * **Dado que** estoy autenticado en la tienda navegando por el catálogo,
        * **cuando** hago clic en el icono de corazón de un artículo deportivo,
        * **entonces** el sistema añade el `product_id` a la tabla relacional de listas de deseos, permitiendo consultarla o remover ítems de ella en cualquier momento.
