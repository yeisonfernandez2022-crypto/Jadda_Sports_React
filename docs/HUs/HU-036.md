### HU-036 — Crear y gestionar una lista de deseos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-036 |
| **Título** | Crear y gestionar una lista de deseos |
| **Módulo** | Interacción de usuarios |
| **Prioridad** | Baja |
| **Estado** | Implementada |
| **RF asociados** | RF-036 |

* **Historia:** Como cliente registrado, **quiero** guardar productos en una lista de deseos personalizada, **para** realizar el seguimiento de mis artículos favoritos y poder agregarlos a mi carrito de compras más adelante.
* **Criterios de aceptación:**
    * **CA-036.1 — Agregar a favoritos:**
        * **Dado que** estoy autenticado y navego el catálogo,
        * **cuando** hago clic en el icono de corazón de un producto,
        * **entonces** el backend agrega el producto a la tabla `FAVORITOS` mediante `POST /api/favoritos`.
    * **CA-036.2 — Ver lista de favoritos:**
        * **Dado que** tengo productos favoritos,
        * **cuando** accedo a la página `/favoritos`,
        * **entonces** veo la lista completa de mis productos guardados obtenida mediante `GET /api/favoritos`.
    * **CA-036.3 — Eliminar de favoritos:**
        * **Dado que** ya no deseo tener un producto en favoritos,
        * **cuando** hago clic nuevamente en el corazón o en el botón de eliminar,
        * **entonces** el backend lo remueve mediante `DELETE /api/favoritos/:id`.
