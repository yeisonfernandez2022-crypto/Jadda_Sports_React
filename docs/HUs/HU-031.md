### HU-031 — Cambiar el estado de los pedidos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-031 |
| **Título** | Cambiar el estado de los pedidos |
| **Módulo** | Panel de administración / Pedidos |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **RF asociados** | RF-031 |

* **Historia:** Como operador logístico, **quiero** transicionar el estado de una orden e ingresar su número de guía de transporte, **para** avanzar en el flujo operativo y habilitar los datos de seguimiento para el comprador.
* **Criterios de aceptación:**
    * **CA-031.1 — Validación de tracking obligatorio:**
        * **Dado que** cambio el estado de una orden a enviado (`shipped`),
        * **cuando** envío la petición al endpoint administrativo,
        * **entonces** el sistema me exige de manera obligatoria ingresar el string del campo `tracking_number` para poder completar con éxito la actualización.
