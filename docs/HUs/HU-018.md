### HU-018 — Seleccionar el método de pago
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-018 |
| **Título** | Seleccionar el método de pago |
| **Módulo** | Checkout / Pasarela de pagos |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **RF asociados** | RF-018 |

* **Historia:** Como cliente con distintas tarjetas o cuentas bancarias, **quiero** elegir mi pasarela o método transaccional preferido, **para** pagar el pedido de la forma que más me convenga.
* **Criterios de aceptación:**
    * **CA-018.1 — Conectividad externa con pasarelas:**
        * **Dado que** selecciono Stripe o MercadoPago en las opciones del formulario,
        * **cuando** confirmo la vía de facturación,
        * **entonces** el backend procesa la petición de manera segura, inicializa las credenciales del servicio externo y retorna el token o ID de sesión correspondiente para completar el recaudo.
