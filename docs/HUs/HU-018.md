### HU-018 — Seleccionar el método de pago
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-018 |
| **Título** | Seleccionar el método de pago |
| **Módulo** | Checkout / Pasarela de pagos |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-018 |

* **Historia:** Como cliente con distintas tarjetas o cuentas bancarias, **quiero** elegir mi pasarela o método transaccional preferido, **para** pagar el pedido de la forma que más me convenga.
* **Criterios de aceptación:**
    * **CA-018.1 — Selección de método de pago:**
        * **Dado que** estoy en el checkout,
        * **cuando** veo las opciones de pago disponibles,
        * **entonces** puedo elegir entre Tarjera crédito/débito, PSE, Nequi o Daviplata.
    * **CA-018.2 — Procesamiento del pago:**
        * **Dado que** seleccioné un método de pago y confirmo la compra,
        * **cuando** envío los datos al backend mediante `POST /api/checkout`,
        * **entonces** el sistema procesa el pago y redirige a la página de confirmación.
