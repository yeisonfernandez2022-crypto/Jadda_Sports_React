### HU-032 — Generar reportes de ventas
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-032 |
| **Título** | Generar reportes de ventas |
| **Módulo** | Panel de administración / Analítica |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **RF asociados** | RF-032 |

* **Historia:** Como director comercial, **quiero** generar reportes económicos seleccionando rangos específicos de fechas, **para** evaluar la facturación, el ticket promedio y el volumen global de pedidos concretados en la tienda.
* **Criterios de aceptación:**
    * **CA-032.1 — Consolidación de KPI financieros:**
        * **Dado que** escojo una fecha de inicio y una de fin en el módulo analítico,
        * **cuando** solicito el informe estadístico,
        * **entonces** el sistema realiza los cálculos de agregación y devuelve los ingresos brutos, el número de compras totales y la media económica de las transacciones.
