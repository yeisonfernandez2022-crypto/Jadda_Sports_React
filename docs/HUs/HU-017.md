### HU-017 — Ingresar la dirección de envío
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-017 |
| **Título** | Ingresar la dirección de envío |
| **Módulo** | Checkout / Pedidos |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-017 |

* **Historia:** Como comprador, **quiero** especificar mi dirección exacta de entrega durante el checkout, **para** asegurar que el paquete de mi pedido llegue de forma correcta a mi domicilio.
* **Criterios de aceptación:**
    * **CA-017.1 — Crear dirección:**
        * **Dado que** estoy en el checkout o en mi perfil,
        * **cuando** completo los campos (dirección, ciudad, departamento, teléfono de contacto) y guardo,
        * **entonces** la dirección se almacena en la tabla `DIRECCIONES` asociada a mi usuario.
    * **CA-017.2 — Seleccionar dirección existente:**
        * **Dado que** ya tengo direcciones guardadas,
        * **cuando** estoy en el checkout,
        * **entonces** puedo seleccionar una dirección existente o agregar una nueva.
    * **CA-017.3 — Editar y eliminar direcciones:**
        * **Dado que** gestiono mis direcciones desde el perfil,
        * **cuando** edito o elimino una dirección,
        * **entonces** los cambios se reflejan mediante los endpoints PUT y DELETE de `/api/direcciones`.
