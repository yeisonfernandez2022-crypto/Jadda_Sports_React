### HU-014 — Gestionar el carrito de compras
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-014 |
| **Título** | Gestionar el carrito de compras |
| **Módulo** | Carrito de compras |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-014 |

* **Historia:** Como cliente, **quiero** añadir, actualizar y quitar variantes de productos de mi carrito de compras, **para** consolidar la lista de ítems que deseo adquirir en una sola transacción.
* **Criterios de aceptación:**
    * **CA-014.1 — Agregar al carrito:**
        * **Dado que** estoy en la página de un producto,
        * **cuando** selecciono una variante (color + talla) y hago clic en "Agregar al carrito",
        * **entonces** el producto se añade al carrito mediante POST `/api/carrito/agregar` y se actualiza el contador del carrito flotante.
    * **CA-014.2 — Ver carrito:**
        * **Dado que** tengo productos en el carrito,
        * **cuando** abro el carrito flotante,
        * **entonces** veo la lista de productos con sus variantes, cantidades, precios y subtotales.
    * **CA-014.3 — Actualizar cantidad:**
        * **Dado que** tengo un producto en el carrito,
        * **cuando** modifico su cantidad,
        * **entonces** se actualiza mediante PUT `/api/carrito/actualizar/:id`.
    * **CA-014.4 — Eliminar del carrito:**
        * **Dado que** ya no deseo un producto,
        * **cuando** hago clic en eliminar,
        * **entonces** se remueve mediante DELETE `/api/carrito/eliminar/:id`.
