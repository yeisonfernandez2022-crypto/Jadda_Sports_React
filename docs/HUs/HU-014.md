### HU-014 — Gestionar el carrito de compras
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-014 |
| **Título** | Gestionar el carrito de compras |
| **Módulo** | Carrito de compras |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **RF asociados** | RF-014 |

* **Historia:** Como cliente, **quiero** añadir, actualizar y quitar variantes de productos de mi carrito de compras, **para** consolidar la lista de ítems que deseo adquirir en una sola transacción.
* **Criterios de aceptación:**
    * **CA-014.1 — Validación contra stock:**
        * **Dado que** modifico la cantidad de un ítem dentro del carrito,
        * **cuando** el volumen deseado excede las unidades físicas en inventario,
        * **entonces** el sistema revierte el cambio y muestra la advertencia: "Requested quantity exceeds available stock".
    * **CA-014.2 — Fusión de carritos al iniciar sesión:**
        * **Dado que** agregué productos de manera anónima (`localStorage`),
        * **cuando** realizo el inicio de sesión con éxito,
        * **entonces** el sistema unifica automáticamente dichos ítems con las líneas de la tabla `cart_items` asociadas a mi ID de usuario.
