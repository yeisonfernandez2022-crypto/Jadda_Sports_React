### HU-003 — Recuperación de contraseña
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-003 |
| **Título** | Recuperación de contraseña |
| **Módulo** | Autenticación |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **RF asociados** | RF-003 |

* **Historia:** Como usuario olvidadizo, **quiero** solicitar el restablecimiento de mi contraseña mediante mi correo electrónico, **para** recuperar el acceso a mi cuenta sin comprometer la seguridad.
* **Criterios de aceptación:**
    * **CA-003.1 — Solicitud de enlace:**
        * **Dado que** olvidé mi clave de acceso,
        * **cuando** ingreso mi correo electrónico en la sección correspondiente y envío la solicitud,
        * **entonces** el sistema me muestra un mensaje de confirmación de envío.
    * **CA-003.2 — Consumo de token y cambio exitoso:**
        * **Dado que** recibí el correo con el token dinámico,
        * **cuando** abro el enlace e introduzco una nueva contraseña válida que cumple las reglas de seguridad,
        * **entonces** el sistema actualiza la contraseña e invalida el token.
    * **CA-003.3 — Token vencido:**
        * **Dado que** ha transcurrido más de sesenta (60) minutos desde que solicité el cambio,
        * **cuando** intento usar el enlace recibido,
        * **entonces** el sistema rechaza la operación y muestra el error: "Token invalid or expired".
