### HU-003 — Recuperación de contraseña
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-003 |
| **Título** | Recuperación de contraseña |
| **Módulo** | Autenticación |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-003 |

* **Historia:** Como usuario olvidadizo, **quiero** solicitar el restablecimiento de mi contraseña mediante mi correo electrónico, **para** recuperar el acceso a mi cuenta sin comprometer la seguridad.
* **Criterios de aceptación:**
    * **CA-003.1 — Solicitud de código:**
        * **Dado que** olvidé mi contraseña,
        * **cuando** ingreso mi correo en la pantalla de recuperación y envío,
        * **entonces** el sistema envía un código de 6 dígitos a mi correo y muestra el mensaje "Código enviado correctamente".
    * **CA-003.2 — Cambio de contraseña exitoso:**
        * **Dado que** recibí el código de 6 dígitos,
        * **cuando** ingreso el código y una nueva contraseña válida,
        * **entonces** el sistema actualiza la contraseña y muestra: "Contraseña actualizada con éxito. El código ha sido invalidado".
    * **CA-003.3 — Código incorrecto:**
        * **Dado que** ingreso un código que no coincide,
        * **cuando** intento cambiar la contraseña,
        * **entonces** el sistema muestra: "Código incorrecto o ya utilizado".
    * **CA-003.4 — Código vencido:**
        * **Dado que** el código ha expirado,
        * **cuando** intento usarlo,
        * **entonces** el sistema muestra: "El código ha expirado".
