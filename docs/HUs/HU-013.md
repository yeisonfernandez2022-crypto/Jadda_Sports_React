### HU-013 — Mostrar las opiniones y valoraciones de otros compradores
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-013 |
| **Título** | Mostrar las opiniones y valoraciones de otros compradores |
| **Módulo** | Catálogo de productos / Feedback |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **RF asociados** | RF-013 |

* **Historia:** Como comprador precavido, **quiero** leer las reseñas y ver la puntuación de estrellas promedio de un producto, **para** tomar una decisión de compra informada basándome en la experiencia de otros.
* **Criterios de aceptación:**
    * **CA-013.1 — Despliegue e integración analítica:**
        * **Dado que** reviso la pestaña de opiniones de un artículo,
        * **cuando** se renderiza la sección,
        * **entonces** calcula el promedio de estrellas general, la cantidad total de reseñas y despliega los textos testimoniales de forma cronológica descendente.
