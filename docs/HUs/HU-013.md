### HU-013 — Mostrar las opiniones y valoraciones de otros compradores
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-013 |
| **Título** | Mostrar las opiniones y valoraciones de otros compradores |
| **Módulo** | Catálogo de productos / Feedback |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-013 |

* **Historia:** Como comprador precavido, **quiero** leer las reseñas y ver la puntuación de estrellas promedio de un producto, **para** tomar una decisión de compra informada basándome en la experiencia de otros.
* **Criterios de aceptación:**
    * **CA-013.1 — Visualización de reseñas:**
        * **Dado que** estoy en la página de detalle de un producto,
        * **cuando** se renderiza la sección de reseñas,
        * **entonces** veo el promedio de estrellas, la cantidad total de reseñas y los comentarios de otros compradores ordenados del más reciente al más antiguo.
    * **CA-013.2 — Promedio calculado del backend:**
        * **Dado que** el frontend solicita las reseñas,
        * **cuando** se hace GET a `/api/productos/:id/resenas`,
        * **entonces** el backend devuelve el `average_rating`, `total_reviews` y la lista de reseñas desde la tabla `RESENAS`.
