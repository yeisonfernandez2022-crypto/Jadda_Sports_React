### HU-011 — Mostrar la disponibilidad de los productos en inventario
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-011 |
| **Título** | Mostrar la disponibilidad de los productos en inventario |
| **Módulo** | Catálogo de productos / Inventario |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-011 |

* **Historia:** Como comprador, **quiero** ver el stock físico de unidades de cada talla o variación al momento de revisar el producto, **para** evitar agregar ítems agotados a mi carrito.
* **Criterios de aceptación:**
    * **CA-011.1 — Stock por variante:**
        * **Dado que** estoy en la página de detalle de un producto,
        * **cuando** veo las variantes disponibles,
        * **entonces** cada variante muestra su stock actual obtenido desde GET `/api/productos/:id/variantes`.
    * **CA-011.2 — Control de stock en selector:**
        * **Dado que** selecciono un color y talla específicos,
        * **cuando** la variante tiene stock 0,
        * **entonces** se muestra como agotada y no se puede agregar al carrito.
