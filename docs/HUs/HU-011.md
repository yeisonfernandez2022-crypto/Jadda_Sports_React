### HU-011 — Mostrar la disponibilidad de los productos en inventario
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-011 |
| **Título** | Mostrar la disponibilidad de los productos en inventario |
| **Módulo** | Catálogo de productos / Inventario |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **RF asociados** | RF-011 |

* **Historia:** Como comprador, **quiero** ver el stock físico de unidades de cada talla o variación al momento de revisar el producto, **para** evitar agregar ítems agotados a mi carrito.
* **Criterios de aceptación:**
    * **CA-011.1 — Desglose de existencias por SKU:**
        * **Dado que** estoy visualizando la página de detalle de un calzado deportivo,
        * **cuando** elijo una talla o variante en el selector,
        * **entonces** el sistema lee el campo `quantity_available` de la tabla de variantes y me muestra dinámicamente las unidades remanentes reales.
