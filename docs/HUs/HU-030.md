### HU-030 — Visualizar todos los pedidos realizados
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-030 |
| **Título** | Visualizar todos los pedidos realizados |
| **Módulo** | Panel de administración / Pedidos |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-030 |

* **Historia:** Como operador de despachos, **quiero** examinar de manera centralizada todas las órdenes de compra efectuadas por los usuarios, **para** organizar los flujos de embalaje y preparación de pedidos del día.
* **Criterios de aceptación:**
    * **CA-030.1 — Consolidado con filtros administrativos:**
        * **Dado que** accedo a la sección de gestión de órdenes del backoffice con rol apto,
        * **cuando** el sistema carga la vista,
        * **entonces** presenta un listado paginado que permite filtrar los pedidos por rangos de fecha, estados operativos o identificadores de cliente.
