### HU-046 — Subir imágenes de productos desde el panel administrador
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-046 |
| **Título** | Subida de imágenes (admin) |
| **Módulo** | Panel de administración / Catálogo |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-046 |

* **Historia:** Como administrador, **quiero** subir imágenes de productos desde mi computador (o pegar una URL) desde el panel, **para** publicar o editar productos con fotografías reales sin depender de otros sistemas.
* **Criterios de aceptación:**
    * **CA-046.1 — Subir imágenes desde el computador:**
        * **Dado que** soy administrador y estoy en el modal de crear o en la edición de un producto,
        * **cuando** uso el componente de subida (`SubirImagenes`) y selecciono archivos (jpg/png/webp/gif),
        * **entonces** veo los previews de las imágenes y el sistema las guarda con `POST /api/productos/imagenes` devolviendo las URLs.
    * **CA-046.2 — Pegar una URL:**
        * **Dado que** tengo la URL de una imagen,
        * **cuando** la pego en el campo "o pega una URL",
        * **entonces** la URL se agrega a la galería del producto.
    * **CA-046.3 — Quitar una imagen:**
        * **Dado que** agregué una imagen por error,
        * **cuando** hago clic en el botón ✕ y confirmo en el diálogo,
        * **entonces** la imagen se quita de la galería sin guardarse al producto.
    * **CA-046.4 — Orden de las imágenes:**
        * **Dado que** tengo varias imágenes,
        * **cuando** uso las flechas ◀ ▶ para reordenarlas,
        * **entonces** la primera queda marcada como "Portada" y el orden se persiste (`IMAGENES` con ORDEN 1..N) al guardar el producto.
    * **CA-046.5 — Guardar producto con imágenes:**
        * **Dado que** terminé de cargar las imágenes,
        * **cuando** guardo el producto (crear o actualizar),
        * **entonces** las URLs se insertan en `PRODUCTO_IMAGENES` con su orden y el producto las muestra en la tienda.
    * **CA-046.6 — Validación de tamaño:**
        * **Dado que** el conjunto de imágenes supera el límite de 25 MB,
        * **cuando** intento subirlas,
        * **entonces** el sistema responde 400 indicando el límite excedido.
