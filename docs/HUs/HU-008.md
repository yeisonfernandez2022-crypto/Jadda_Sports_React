### HU-008 — Ordenar los productos por precio
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-008 |
| **Título** | Ordenar los productos por precio |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-008 |

* **Historia:** Como comprador consciente de mi presupuesto, **quiero** reordenar la lista de artículos según su precio, **para** identificar rápidamente las ofertas o los productos tope de gama.
* **Criterios de aceptación:**
    * **CA-008.1 — Orden ascendente/descendente:**
        * **Dado que** estoy en el catálogo,
        * **cuando** selecciono "Menor precio" o "Mayor precio",
        * **entonces** la lista se reordena mediante GET `/api/productos?orden=asc` o `orden=desc`.
