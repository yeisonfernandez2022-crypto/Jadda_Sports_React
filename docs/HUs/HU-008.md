### HU-008 — Ordenar los productos por precio
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-008 |
| **Título** | Ordenar los productos por precio |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **RF asociados** | RF-008 |

* **Historia:** Como comprador con presupuesto limitado, **quiero** ordenar el listado de productos de menor a mayor precio o viceversa, **para** comparar los costos cómodamente.
* **Criterios de aceptación:**
    * **CA-008.1 — Orden Ascendente y Descendente:**
        * **Dado que** tengo un listado de productos en pantalla,
        * **cuando** cambio el selector de ordenamiento a precio menor-mayor (`asc`) o precio mayor-menor (`desc`),
        * **entonces** el backend ejecuta la instrucción `ORDER BY price` respectiva y refresca la cuadrícula sin perder los filtros actuales.
