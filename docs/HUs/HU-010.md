### HU-010 — Mostrar la descripción detallada de cada producto
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-010 |
| **Título** | Mostrar la descripción detallada de cada producto |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-010 |

* **Historia:** Como cliente interesado, **quiero** hacer clic en un producto, **para** ver su ficha técnica detallada, imágenes complementarias y las opciones de tallas o colores disponibles.
* **Criterios de aceptación:**
    * **CA-010.1 — Detalle del producto:**
        * **Dado que** hago clic en un producto del catálogo,
        * **cuando** navego a `/producto/:id`,
        * **entonces** veo el nombre, precio, descripción, marca, imágenes y variantes disponibles (color, talla, stock) obtenidos desde GET `/api/productos/:id`.
    * **CA-010.2 — Variantes y stock:**
        * **Dado que** estoy en la página del producto,
        * **cuando** selecciono un color,
        * **entonces** se muestran las tallas disponibles con su stock correspondiente.
    * **CA-010.3 — Producto no encontrado:**
        * **Dado que** el ID del producto no existe,
        * **cuando** se carga la página,
        * **entonces** veo un mensaje de error: "Producto no encontrado".
