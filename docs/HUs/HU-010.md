### HU-010 — Mostrar la descripción detallada de cada producto
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-010 |
| **Título** | Mostrar la descripción detallada de cada producto |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **RF asociados** | RF-010 |

* **Historia:** Como cliente interesado, **quiero** hacer clic en un producto, **para** ver su ficha técnica detallada, imágenes complementarias y las opciones de tallas o colores disponibles.
* **Criterios de aceptación:**
    * **CA-010.1 — Carga completa mediante JOINs:**
        * **Dado que** selecciono un producto específico del listado,
        * **cuando** navego a su ruta detallada (`/products/{id}`),
        * **entonces** el backend reúne la información comercial, variantes de SKUs e imágenes secundarias en un solo payload JSON.
    * **CA-010.2 — Producto inexistente:**
        * **Dado que** introduzco un ID aleatorio en la URL del producto,
        * **cuando** el sistema ejecuta la búsqueda y no halla coincidencia,
        * **entonces** renderiza un estado de error 404: "Product not found".
