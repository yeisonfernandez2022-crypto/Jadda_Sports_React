### HU-042 — Gestionar métodos de pago guardados en el perfil
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-042 |
| **Título** | Métodos de pago guardados |
| **Módulo** | Usuario / Pagos |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-042 |

* **Historia:** Como cliente registrado, **quiero** guardar y gestionar mis métodos de pago en mi perfil, **para** agilizar mis futuras compras sin tener que ingresarlos cada vez.
* **Criterios de aceptación:**
    * **CA-042.1 — Listar mis métodos de pago:**
        * **Dado que** tengo métodos de pago guardados,
        * **cuando** accedo a `/perfil/metodos-pago`,
        * **entonces** veo la lista obtenida con `GET /api/usuarios/metodos-pago`, incluyendo cuál es el principal.
    * **CA-042.2 — Guardar un método de pago:**
        * **Dado que** quiero guardar un nuevo método,
        * **cuando** ingreso el método (tarjeta, Nequi, Daviplata, PSE) y lo confirmo,
        * **entonces** el sistema lo guarda con `POST /api/usuarios/metodos-pago` y, si es el primero, lo marca automáticamente como principal.
    * **CA-042.3 — Validación del tipo de método:**
        * **Dado que** intento guardar un método con un tipo inválido,
        * **cuando** envío el formulario,
        * **entonces** el sistema responde 400 con un mensaje descriptivo (el tipo debe existir en `METODOS_PAGO`).
    * **CA-042.4 — Marcar método principal:**
        * **Dado que** tengo varios métodos guardados,
        * **cuando** marco uno como principal,
        * **entonces** ese método pasa a ser el predeterminado mediante `PUT /api/usuarios/metodos-pago/:id/principal`.
    * **CA-042.5 — Eliminar método:**
        * **Dado que** ya no quiero un método guardado,
        * **cuando** lo elimino (confirmando con el diálogo de SweetAlert),
        * **entonces** el sistema lo remueve con `DELETE /api/usuarios/metodos-pago/:id`.
    * **CA-042.6 — Sincronización con el checkout:**
        * **Dado que** guardo un método durante el pago (checkbox "Guardar este método" marcado por defecto),
        * **cuando** finalizo la compra,
        * **entonces** el método aparece en mi perfil; y un método principal guardado se precarga en el resumen de compra.
