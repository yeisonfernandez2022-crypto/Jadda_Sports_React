### HU-026 — Calificar su experiencia de compra
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-026 |
| **Título** | Calificar su experiencia de compra |
| **Módulo** | Feedback |
| **Prioridad** | Baja |
| **Estado** | Implementada |
| **RF asociados** | RF-026 |

* **Historia:** Como comprador verificado, **quiero** dejar una reseña escrita y asignar estrellas a los productos deportivos que compré, **para** compartir mi experiencia real con el resto de la comunidad.
* **Criterios de aceptación:**
    * **CA-026.1 — Dejar reseña desde la página del producto:**
        * **Dado que** estoy autenticado y veo la sección de reseñas de un producto,
        * **cuando** hago clic en las estrellas, escribo un comentario y envío,
        * **entonces** la reseña se guarda en la tabla `RESENAS` mediante `POST /api/productos/:id/resenas` y se muestra el mensaje "Reseña agregada correctamente".
    * **CA-026.2 — Reseña desde compra exitosa:**
        * **Dado que** acabo de realizar una compra,
        * **cuando** veo la pantalla de compra exitosa,
        * **entonces** puedo seleccionar productos comprados y dejar una reseña con calificación y comentario.
    * **CA-026.3 — Reseña sin autenticación:**
        * **Dado que** no he iniciado sesión,
        * **cuando** intento dejar una reseña,
        * **entonces** el sistema me redirige al login o muestra un mensaje indicando que debo iniciar sesión.
