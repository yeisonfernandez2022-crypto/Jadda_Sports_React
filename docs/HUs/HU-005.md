### HU-005 — Cierre de sesión seguro
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-005 |
| **Título** | Cierre de sesión seguro |
| **Módulo** | Autenticación |
| **Prioridad** | Alta |
| **Estado** | Implementada |
| **RF asociados** | RF-005 |

* **Historia:** Como usuario consciente de la seguridad, **quiero** cerrar mi sesión de forma explícita, **para** asegurar que nadie más pueda usar mi cuenta desde este dispositivo.
* **Criterios de aceptación:**
    * **CA-005.1 — Cierre de sesión:**
        * **Dado que** tengo una sesión activa,
        * **cuando** pulso el botón "Cerrar sesión",
        * **entonces** el sistema destruye la sesión en el servidor, redirige al usuario a la página de inicio y limpia los datos de sesión del frontend.
    * **CA-005.2 — Confirmación visual:**
        * **Dado que** cierro sesión exitosamente,
        * **cuando** se completa el proceso,
        * **entonces** la barra de navegación debe mostrar los botones de "Iniciar sesión" y "Registrarme" en lugar del menú de usuario.
