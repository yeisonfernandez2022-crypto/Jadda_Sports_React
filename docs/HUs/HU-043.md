### HU-043 — Notificaciones in-app (campana de avisos)
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | HU-043 |
| **Título** | Notificaciones in-app |
| **Módulo** | Usuario / Notificaciones |
| **Prioridad** | Media |
| **Estado** | Implementada |
| **RF asociados** | RF-043 |

* **Historia:** Como usuario autenticado, **quiero** recibir y gestionar avisos dentro de la aplicación a través de una campana, **para** estar al tanto de los eventos importantes de mis pedidos y de la plataforma sin depender del correo.
* **Criterios de aceptación:**
    * **CA-043.1 — Ver notificaciones:**
        * **Dado que** estoy autenticado,
        * **cuando** abro la campana de notificaciones,
        * **entonces** veo la lista de avisos obtenida con `GET /api/notificaciones`, ordenada por fecha y con su estado leído/no leído.
    * **CA-043.2 — Contador de no leídas:**
        * **Dado que** tengo notificaciones sin leer,
        * **cuando** la campana se renderiza,
        * **entonces** muestra un badge con el total de no leídas (`GET /api/notificaciones/no-leidas`).
    * **CA-043.3 — Marcar una notificación como leída:**
        * **Dado que** abro una notificación,
        * **cuando** hago clic en ella,
        * **entonces** solo esa notificación se marca como leída (`POST /api/notificaciones/:id/leida`) y el contador disminuye.
    * **CA-043.4 — Marcar todas como leídas:**
        * **Dado que** tengo varias notificaciones sin leer,
        * **cuando** elijo "marcar todas como leídas",
        * **entonces** todas se actualizan con `POST /api/notificaciones/leer-todas` y el contador vuelve a cero.
    * **CA-043.5 — Navegación desde la notificación:**
        * **Dado que** hago clic en una notificación con ruta de destino (por ejemplo, `/perfil/compras`),
        * **cuando** se abre,
        * **entonces** el sistema me redirige a la sección correspondiente.
    * **CA-043.6 — Notificaciones globales visibles para el admin:**
        * **Dado que** soy administrador,
        * **cuando** abro mi campana,
        * **entonces** veo las notificaciones globales (sin usuario destino) además de las mías propias.
