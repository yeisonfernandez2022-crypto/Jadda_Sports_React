# Bitácora de Lecciones Aprendidas

**Proyecto:** JADDA SPORTS · Ciclo de vida 2025-2026
**Método:** cada lección proviene de un defecto u obstáculo REAL encontrado durante el desarrollo, con su causa raíz y la acción que lo previene. Esta bitácora alimenta el informe de calidad y el plan de mejora continua.

| # | Fecha | Categoría | Lección aprendida | Acción preventiva |
|---|-------|-----------|-------------------|-------------------|
| 1 | 2026-08 | Frontend/React | Vaciar un input de archivos con `e.target.value = ""` **sincrónicamente dentro del onChange** destruye la FileList viva en React 19: el estado pierde los archivos recién seleccionados (detectado en E2E: "files en input: 0"). | Diferir el reset: `setTimeout(() => { e.target.value = "" }, 0)`. Documentado como patrón del proyecto. |
| 2 | 2026-08 | SQL/Backend | mysql2 devuelve las claves del resultado **con el nombre exacto escrito en la consulta**: `SELECT *` sobre columnas en minúsculas (`foto_url`) hizo que `user.FOTO_URL` fuera `undefined` y la app móvil perdiera la foto al re-loguear. | Alias explícito en mayúsculas para todo campo consumido por el frontend; nunca confiar en `SELECT *` cruzando capas. |
| 3 | 2026-07 | SQL/Backend | Un LEFT JOIN nullable rompe `SELECT ... FOR UPDATE` en MySQL ("Locking clauses are only allowed in outer joins of two tables" / comportamiento indefinido). | Separar la fila bloqueada (VENTAS FOR UPDATE) de los datos complementarios (ENVIOS) en dos consultas dentro de la misma transacción. |
| 4 | 2026-07 | SQL/Backend | Cada `?` debe tener parámetro en TODAS las ramas lógicas: una consulta de respaldo quedó sin su array → ERROR 1064 "near '?'" solo en el fallback. | Probar SIEMPRE también la rara rama alternativa (fallback), no solo el caso feliz. |
| 5 | 2026-06 | DevOps/Docker | Docker Desktop no propaga carpetas/archivos nuevos a los contenedores al instante; Vite sirvió el index.html para una foto recién subida (200 text/html → imagen "dañada"). | Servir archivos dinámicos desde Express (express.static siempre fresco) + proxy `/images`; reiniciar el contenedor frontend si hay caché stale. |
| 6 | 2026-08 | DevOps/Docker | El dev server de Vite en Docker conserva errores de parseo viejos aunque el código ya esté corregido. | `docker restart jadda_frontend` tras cambios grandes; documentado en troubleshooting. |
| 7 | 2026-08 | Tooling/Windows | PowerShell 5.1 **elimina las comillas dobles internas** al pasar argumentos a ejecutables nativos (docker.exe): `-e "CREATE DATABASE..."` llega como `-e CREATE...` → ERROR 1064. También convierte stderr de mysqldump en error terminante con `$ErrorActionPreference="Stop"`. | Para SQL: escribir .sql a archivo + `docker cp` + `mysql < archivo`. En scripts: comillas simples de sh vía `[char]39`, password sin comillas, y bajar EAP alrededor de comandos nativos. |
| 8 | 2026-08 | Tooling/Windows | `Add-Content` pega texto al final si el archivo no termina en salto de línea: `.gitignore` quedó `mysql_data/backups/` ignorando rutas equivocadas. | Verificar salto final antes de append; preferir reescritura completa (`Set-Content`). |
| 9 | 2026-06 | Frontend/CSS | Dos navbars fixed apilados (global + local por página): el segundo interceptaba clicks del primero — el menú móvil no abría aunque "se veía bien". | Auditar overlays duplicados con `elementFromPoint`; fuente única de verdad: AppLayout renderiza el Navbar global. |
| 10 | 2026-06 | Frontend/CSS | Z-index sin jerarquía global: modales admin (1400) quedaban bajo el navbar público (9990) y los Swal bajo ambos. | Escala centralizada: navbar admin 1040 < público 9990 < modales/Swal 10050. |
| 11 | 2026-05 | Testing/E2E | `isVisible()` corre antes del montaje de React y falla espurio; `translateX(-105%)` no hace invisible un elemento para Playwright. | Esperar selectores con `waitForSelector`; medir geometría real (`getBoundingClientRect().right <= 0`) para elementos desplazados. |
| 12 | 2026-05 | Testing/E2E | Cookies de sesión con `expires: 0` se consideran expiradas al inyectarlas en Playwright → 401 fantasma. | Inyectar `sameSite:'Lax'` y omitir expires cuando vale 0. |
| 13 | 2026-04 | Datos/Seeds | `INSERT IGNORE` no actualiza filas existentes: cambiar seeds (ej. % de retos) en setup.js NO modifica una BD viva. | Los cambios de datos de referencia requieren UPDATE manual/migración documentada, no basta re-seed. |
| 14 | 2026-04 | Proceso | Cambiar endpoints/rutas de UI rompió fetch del API en otro archivo (`/api/producto/` vs `/api/productos/`): un rename textual afectó más de lo previsto. | Renombres globales siempre con verificación posterior de build + smoke test de las pantallas afectadas. |
| 15 | 2026-03 | Seguridad | Interpolar datos del usuario en `html:` de SweetAlert2 permite XSS almacenado (nombres de producto/categoría). | Helper `escapeHtml.ts` obligatorio antes de cualquier interpolación en html/title. |
| 16 | 2026-02 | Build/TS | En monorepo con referencias TS, `tsc --noEmit` en la raíz no revisa nada; los errores aparecían solo en el build de Docker. | Comando canónico del proyecto: `npx tsc -b` antes de cada entrega. |
