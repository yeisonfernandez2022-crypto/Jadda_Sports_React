## MÓDULO 11: MANEJO DE ERRORES Y EXPERIENCIA DE USUARIO (RNF-011)

### Identificación:

| Campo | Valor |
| :--- | :--- |
| **ID** | RNF-011 |
| **Nombre** | Manejo de Errores |
| **Categoría** | Experiencia de usuario |
| **Prioridad** | Alta |
| **Estado** | Implementado |

### Requisitos:

* **RNF-011.1 — Estados de carga:**
    * Toda operación asíncrona (login, registro, checkout, búsqueda) debe mostrar un indicador de carga mientras se procesa.
* **RNF-011.2 — Mensajes de error descriptivos:**
    * Los errores deben mostrar mensajes claros en español que indiquen qué salió mal y cómo solucionarlo.
* **RNF-011.3 — Sin errores técnicos visibles:**
    * Los errores del servidor (500) nunca deben mostrar stack traces al usuario; deben mostrar un mensaje genérico.
* **RNF-011.4 — Confirmación de acciones destructivas:**
    * Las acciones como eliminar dirección, eliminar producto del carrito o cancelar compra deben solicitar confirmación antes de ejecutarse.
* **RNF-011.5 — Feedback visual en agregar al carrito:**
    * Al agregar un producto al carrito, debe mostrarse una notificación visual (ej. SweetAlert2) confirmando la acción.
* **RNF-011.6 — Manejo de errores de red:**
    * Si el backend no responde, el frontend debe mostrar un mensaje indicando problemas de conexión, no una pantalla en blanco.
