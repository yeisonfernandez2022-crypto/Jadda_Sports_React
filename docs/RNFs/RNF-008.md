## MÓDULO 8: DESPLIEGUE Y DEVOPS (RNF-008)

### Identificación:

| Campo | Valor |
| :--- | :--- |
| **ID** | RNF-008 |
| **Nombre** | Despliegue y DevOps |
| **Categoría** | Infraestructura |
| **Prioridad** | Alta |
| **Estado** | Implementado |

### Requisitos:

* **RNF-008.1 — Contenedores Docker:**
    * El proyecto debe ejecutarse completamente con Docker Compose (backend, frontend, base de datos).
* **RNF-008.2 — Docker compose unificado:**
    * Debe existir un único `docker-compose.yml` en la raíz que orqueste todos los servicios.
* **RNF-008.3 — Auto-setup de base de datos:**
    * Las tablas y datos de referencia deben crearse automáticamente al arrancar el backend mediante `setup.js`.
* **RNF-008.4 — Volumen persistente para MySQL:**
    * Los datos de la base de datos deben persistirse en un volumen nombrado de Docker (`mysql_data`).
* **RNF-008.5 — Variables de entorno para configuración:**
    * Toda configuración del entorno (puertos, credenciales) debe manejarse mediante variables de entorno con valores por defecto.
* **RNF-008.6 — Build de frontend:**
    * El frontend debe poder compilarse con `pnpm build` sin errores de TypeScript ni Vite.
* **RNF-008.7 — Sin credenciales en el repositorio:**
    * Los archivos `.env` y la carpeta `mysql_data/` deben estar en `.gitignore`.
