## MÓDULO 9: APLICACIÓN MÓVIL (RNF-009)

### Identificación:

| Campo | Valor |
| :--- | :--- |
| **ID** | RNF-009 |
| **Nombre** | App Móvil |
| **Categoría** | Plataforma Móvil |
| **Prioridad** | Alta |
| **Estado** | En desarrollo |

### Requisitos:

* **RNF-009.1 — Framework React Native + Expo:**
    * La app móvil debe construirse con React Native y Expo SDK 54. No se permite Kotlin, Swift ni Flutter.
* **RNF-009.2 — File-based routing con Expo Router:**
    * La navegación debe usar Expo Router con estructura de archivos.
* **RNF-009.3 — Bottom tabs:**
    * La navegación principal debe usar bottom tabs (inicio, catálogo, carrito, perfil).
* **RNF-009.4 — URL base configurable:**
    * La URL de la API debe configurarse mediante `EXPO_PUBLIC_API_URL`, no hardcodeada.
* **RNF-009.5 — Persistencia de sesión:**
    * El estado de autenticación debe persistirse con AsyncStorage para mantener la sesión entre usos.
* **RNF-009.6 — Consumo de mismos endpoints:**
    * La app móvil debe consumir los mismos endpoints REST que el frontend web.
