## MÓDULO 2: Tu información viaja protegida (RNF-002)

### Identificación:

| Campo | Valor |
| :--- | :--- |
| **ID** | RNF-002 |
| **Nombre** | Tu información viaja protegida |
| **Categoría** | Seguridad y Privacidad |
| **Prioridad** | Crítica |
| **Estado** | Implementado parcialmente |

### Requisitos:

* **RNF-002.1 — Protocolo HTTPS seguro:**
    * El sistema debe utilizar de manera obligatoria el protocolo HTTPS para todas las comunicaciones entre cliente y servidor, denegando conexiones HTTP inseguras mediante redirecciones forzadas TLS 1.3.
* **RNF-002.2 — Mitigación de vulnerabilidades OWASP (Fuerza bruta, CSRF, XSS):**
    * El sistema debe implementar mecanismos de seguridad avanzados:
    * **Fuerza bruta:** Bloqueo temporal de IP/cuenta tras 5 intentos fallidos de login.
    * **XSS:** Sanitización exhaustiva de entradas HTML y configuración de cabeceras de seguridad.
    * **CSRF:** Validación estricta de tokens antifalsificación en peticiones de mutación de datos.
* **RNF-002.3 — Sesiones con expiración automática:**
    * El sistema debe gestionar sesiones seguras que expiren automáticamente tras un periodo definido de 30 minutos de inactividad del usuario.
* **RNF-002.4 — Almacenamiento de datos sensibles cifrados:**
    * Los datos sensibles persistidos, tales como tokens de pasarelas de pago o identificaciones fiscales, deben estar protegidos mediante cifrado en reposo AES-256.
* **RNF-002.5 — Cumplimiento normativo legal:**
    * El sistema debe ajustarse a las normativas de protección de datos vigentes (Ley de Protección de Datos Personales), garantizando los derechos de acceso, rectificación y supresión de datos a petición del usuario.
* **Estado de implementación:** Parcial.
    * ✅ **Fuerza bruta:** rate limiting en memoria por IP en login (10/15 min), registro (5/15 min), confirmación, recuperación, reenvío y contacto (ver `rateLimiter.js`).
    * ✅ **XSS parcial:** `escapeHtml` en campos de SweetAlert (`utils/escapeHtml.ts`) y validación de tipos en backend.
    * ❌ **HTTPS/TLS**: no implementado (HTTP en desarrollo; requeriría certificado y proxy).
    * ❌ **CSRF (tokens)**: no implementado (mitigado parcialmente por cookie `SameSite` de sesión).
    * ❌ **AES-256 en reposo**: no aplicado (los datos sensibles están en MySQL sin cifrado de columna).
    * ❌ **Ley 1581 (Habeas Data)**: los términos/políticas existen en el registro, pero no hay endpoint de exportación/borrado de datos (derecho de supresión).
