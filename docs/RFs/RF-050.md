### RF-050 — Sistema de chat entre usuarios, vendedores y administración
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-050 |
| **Nombre** | Chat multi-canal del marketplace |
| **Módulo** | Comunicación / Soporte |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Conversaciones en tiempo cercano (polling) de tres tipos: SOPORTE (usuario↔admins), VENDEDOR (usuario↔vendedor para envíos y detalles del producto) y DEVOLUCIÓN (comprador↔vendedor por una solicitud). Cada chat registra autor, rol (CLIENTE/VENDEDOR/ADMIN/SISTEMA), mensaje y estado de lectura. Los mensajes se censuran con asteriscos sobre palabras ofensivas completas (`backend/utils/groserias.js`). El administrador no abre tickets de soporte: responde los existentes. Badge de mensajes sin leer en navbar y paneles.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `tipo` | Enum | Sí | SOPORTE \| VENDEDOR \| DEVOLUCION |
| `id_producto` / `id_devolucion` | Entero | Según tipo | Producto con vendedor; solicitud propia o de sus productos |
| `mensaje` | Texto | Sí (envío) | Máximo 2000 caracteres; censura de groserías |

* **Proceso:**
    1. `POST /api/chat/iniciar` crea o recupera (idempotente) la conversación según tipo.
    2. `GET /api/chat/conversaciones` lista las conversaciones del rol con último mensaje, no leídos y estado.
    3. `GET /api/chat/:id/mensajes` valida participación y marca como leídos los mensajes del otro bando.
    4. `POST /api/chat/:id/mensajes` guarda censurado, actualiza actividad y notifica a la contraparte (a todos los admins en soporte).
    5. `GET /api/chat/no-leidos` devuelve el total sin leer del rol para badges (polling cada 20 s).
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Chat creado/recuperado | 201/200 | `{ ok, id_chat }` |
| Mensaje enviado | 201 | Mensaje con autor y fecha |
| Sin participación | 403 | `{ ok: false, msg }` |
| Admin abre soporte propio | 400 | "El equipo JADDA es el soporte…" |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/chat/iniciar` | Sí | Inicia o recupera conversación |
| GET | `/api/chat/conversaciones` | Sí | Lista mis conversaciones |
| GET | `/api/chat/no-leidos` | Sí | Total de mensajes sin leer |
| GET | `/api/chat/:id/mensajes` | Sí | Mensajes del hilo |
| POST | `/api/chat/:id/mensajes` | Sí | Enviar mensaje |
