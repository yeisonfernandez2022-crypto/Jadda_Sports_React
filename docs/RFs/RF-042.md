### RF-042 — Gestionar métodos de pago guardados en el perfil
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-042 |
| **Nombre** | Métodos de pago guardados |
| **Módulo** | Usuario / Pagos |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Permite al usuario autenticado guardar, listar, eliminar y marcar como principal sus métodos de pago (tarjeta, Nequi, Daviplata, PSE). La sincronización es bidireccional con el checkout: lo guardado al pagar aparece en el perfil y viceversa.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `ID_METODO` | Entero (Body) | Sí | Debe existir en `METODOS_PAGO` (400 si no) |
| `informacion` | Texto (Body) | No | Número/enmascarado del método |
| `titular` | Texto (Body) | No | Titular del método |

* **Proceso:**
    1. El usuario abre `/perfil/metodos-pago` (tarjeta "Métodos de pago" en Perfil).
    2. `guardarMetodo` valida el ID contra `METODOS_PAGO`; si es el primer método se auto-asigna `ES_PRINCIPAL = 1`.
    3. `PUT /:id/principal` cambia el método por defecto; `DELETE /:id` lo elimina.
    4. En `ResumenCompra`, el checkbox "Guardar este método" viene marcado por defecto; al pagar se persiste y el perfil lo recibe.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Métodos listados | 200 | Lista con `ID_METODO`, `INFORMACION`, `ES_PRINCIPAL` |
| Método guardado | 201 | Método creado (principal si es el primero) |
| Método principal actualizado | 200 | Confirmación |
| Método eliminado | 200 | Confirmación |
| ID_METodo inválido | 400 | Mensaje descriptivo |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/usuarios/metodos-pago` | Sí | Lista los métodos guardados |
| POST | `/api/usuarios/metodos-pago` | Sí | Guarda un método |
| PUT | `/api/usuarios/metodos-pago/:id/principal` | Sí | Marca método principal |
| DELETE | `/api/usuarios/metodos-pago/:id` | Sí | Elimina un método |
