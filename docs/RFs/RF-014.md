### RF-014 — Gestionar el carrito de compras
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-014 |
| **Nombre** | Gestionar el carrito de compras |
| **Módulo** | Carrito de compras |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite realizar el ciclo básico de operaciones del carrito (agregar productos, actualizar volúmenes y descartar ítems). Soporta almacenamiento en memoria local para anónimos y base de datos distribuida para usuarios autenticados.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `variant_id` | Entero (Body) | Sí | Debe mapear a un ID de variante de producto válido |
| `quantity` | Entero (Body) | Sí | Valor numérico entero mayor a cero |

* **Proceso:**
    1. El usuario presiona el disparador para alterar su carrito.
    2. El backend verifica la existencia de la variante y comprueba que `quantity` no vulnere el inventario actual.
    3. Si el usuario cuenta con sesión, registra o modifica la tupla correspondiente en la tabla relacional `cart_items`.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Carrito modificado | 200 | Estado general actualizado de los ítems presentes en el carrito |
| Exceso de existencias | 400 | Mensaje de error: `"Requested quantity exceeds available stock"` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/v1/cart` | Opcional | Obtiene el estado del carrito actual del usuario |
| POST | `/api/v1/cart/items` | Opcional | Agrega una variante de producto dentro de las líneas del carrito |
| PUT | `/api/v1/cart/items/{item_id}`| Opcional | Sobreescribe la cantidad asignada a un ítem del carrito |
| DELETE| `/api/v1/cart/items/{item_id}`| Opcional | Elimina definitivamente un ítem de la lista del carrito |

* **Reglas de negocio:**
    * **RN-007:** Al iniciar sesión, el sistema debe fusionar de forma automatizada las líneas guardadas en el `localStorage` del visitante anónimo con los registros de su carrito persistido en la base de datos.
