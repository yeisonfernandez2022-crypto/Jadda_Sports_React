### RF-027 — Gestionar las categorías de productos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-027 |
| **Nombre** | Gestionar las categorías de productos |
| **Módulo** | Panel de administración |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Concede al rol administrador las herramientas para crear, visualizar, modificar y aplicar bajas lógicas sobre las categorías del catálogo de venta.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `name` | Texto (Body) | Sí | Cadena única, longitud entre 3 y 100 caracteres |
| `description` | Texto (Body) | No | Nota descriptiva opcional |

* **Proceso:**
    1. El administrador envía los campos desde el backend de gestión.
    2. El sistema valida el rol (`admin`) mediante las políticas del JWT.
    3. Inserta o modifica el registro en la tabla `categories`, calculando de forma automática el slug url único.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Categoría guardada | 201 | Datos completos de la entidad de categoría persistida en DB |
| Privilegios insuficientes| 403 | Mensaje de error: `"Access denied. Admin role required"` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/v1/admin/categories` | Sí (Admin) | Registra una nueva agrupación de categorías en la base de datos |
| PUT | `/api/v1/admin/categories/{id}`| Sí (Admin) | Edita los atributos informativos de una categoría existente |
| DELETE| `/api/v1/admin/categories/{id}`| Sí (Admin) | Realiza el borrado lógico deshabilitando la categoría |
