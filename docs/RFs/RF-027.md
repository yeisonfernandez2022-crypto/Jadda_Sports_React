### RF-027 — Gestionar las categorías de productos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-027 |
| **Nombre** | Gestionar las categorías de productos |
| **Módulo** | Panel de administración |
| **Prioridad** | Media |
| **Estado** | Parcial |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite visualizar las categorías desde el backend. La creación, modificación y eliminación desde el panel administrador está pendiente.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `name` | Texto (Body) | Sí | Cadena única, longitud entre 3 y 100 caracteres |
| `description` | Texto (Body) | No | Nota descriptiva opcional |

* **Proceso:**
    1. El frontend consulta las categorías disponibles para filtros en el catálogo.
    2. El backend ejecuta `SELECT * FROM CATEGORIAS` y devuelve la lista.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Categorías obtenidas | 200 | Lista de categorías con ID, nombre y descripción |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/productos/categorias` | No | Obtiene el listado de categorías disponibles |
| POST | — | — | Pendiente de implementar |
| PUT | — | — | Pendiente de implementar |
| DELETE | — | — | Pendiente de implementar |
