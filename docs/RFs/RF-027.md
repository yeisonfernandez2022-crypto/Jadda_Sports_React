### RF-027 — Gestionar las categorías de productos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-027 |
| **Nombre** | Gestionar las categorías de productos |
| **Módulo** | Panel de administración |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite visualizar las categorías desde el catálogo y gestionarlas por completo desde el panel administrador: crear, editar y eliminar categorías (la eliminación está bloqueada si la categoría tiene productos asociados).
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `name` | Texto (Body) | Sí | Cadena única, longitud entre 3 y 100 caracteres |
| `description` | Texto (Body) | No | Nota descriptiva opcional, máx 100 caracteres |

* **Proceso:**
    1. El frontend consulta las categorías disponibles para filtros en el catálogo.
    2. El backend ejecuta `SELECT * FROM CATEGORIAS` y devuelve la lista.
    3. El administrador crea/edita/elimina categorías desde el panel (`/admin/categorias`); el backend valida unicidad del nombre y bloquea el borrado si existen productos en la categoría.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Categorías obtenidas | 200 | Lista de categorías con ID, nombre, descripción y total de productos |
| Categoría creada | 201 | `{ok, msg, ID_CATEGORIA}` |
| Categoría actualizada | 200 | `{ok, msg}` |
| Categoría eliminada | 200 | `{ok, msg}` |
| Nombre inválido o duplicado | 400 | `{ok: false, msg}` |
| Categoría con productos | 400 | `{ok: false, msg}` con conteo |
| Categoría inexistente | 404 | `{ok: false, msg}` |
| Sin permisos de admin | 403 | `{ok: false, msg}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/productos/categorias` | No | Obtiene el listado de categorías disponibles |
| POST | `/api/productos/categorias` | Admin | Crea una categoría |
| PUT | `/api/productos/categorias/:id` | Admin | Actualiza nombre/descripción |
| DELETE | `/api/productos/categorias/:id` | Admin | Elimina (bloqueado si tiene productos) |
