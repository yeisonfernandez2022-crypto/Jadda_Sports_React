### RF-047 — Suscribirse al boletín de noticias (Newsletter)
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-047 |
| **Nombre** | Newsletter |
| **Módulo** | Mercadotecnia |
| **Prioridad** | Baja |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Permite a cualquier visitante (logueado o no) suscribir su correo al boletín desde el input del footer. La suscripción se persiste en `backend/data/newsletter.json` (compartido también en el flujo de newsletter del usuario).
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `email` | Texto (Body) | Sí | Formato de correo válido; no duplicado (+1 a la lista) |

* **Proceso:**
    1. El usuario ingresa su email en el Footer y envía `POST /api/newsletter`.
    2. El backend lee/agrega el correo en `backend/data/newsletter.json` (el directorio se crea automáticamente con `mkdirSync recursive`).
    3. Responde éxito; duplicados se ignoran.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Suscripción guardada | 200 | `{ ok: true, mensaje }` |
| Email inválido | 400 | Mensaje descriptivo |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/newsletter` | No | Registra el correo en la lista de Newsletter |
