### RF-022 — Consultar el estado de su pedido
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-022 |
| **Nombre** | Consultar el estado de su pedido |
| **Módulo** | Pedidos |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los compradores ver el estado de su orden de compra (`paid`, `shipped`, `delivered`, `cancelled`) y obtener información logística de seguimiento.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `order_id` | Entero (Path) | Sí | ID de pedido asociado al usuario solicitante |

* **Proceso:**
    1. El cliente consulta el estado del envío en su panel privado de compras.
    2. El backend busca la tupla en la tabla `orders` y devuelve el estado actual del campo enumerado junto con el número de guía de transporte si está disponible.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Consulta exitosa | 200 | JSON: `{"order_id": 12, "status": "shipped", "tracking_number": "TRK123"}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/v1/orders/{order_id}/status`| Sí | Entrega el estado operativo y metadatos de envío de la orden |
