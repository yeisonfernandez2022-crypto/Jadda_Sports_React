### RF-003 — Recuperación de contraseña
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-003 |
| **Nombre** | Recuperación de contraseña |
| **Módulo** | Autenticación |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los usuarios que olvidaron su clave de acceso solicitar un restablecimiento seguro mediante un enlace dinámico de un solo uso enviado a su dirección de correo electrónico.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `email` | Texto (email) | Sí (Fase 1) | Formato válido de email |
| `token` | Texto | Sí (Fase 2) | Estructura UUIDv4 válida |
| `new_password` | Texto | Sí (Fase 2) | Mínimo 8 caracteres, al menos 1 mayúscula, 1 minúscula y 1 número |

* **Proceso:**
    1. El usuario introduce su correo electrónico en el formulario de olvido de contraseña.
    2. El sistema comprueba la existencia del correo electrónico. Si existe, genera un token criptográfico único en la tabla `password_reset_tokens` con una duración fija de expiración.
    3. El sistema envía un correo automatizado al usuario que contiene la dirección URL con el parámetro query token.
    4. El usuario pulsa sobre el enlace, ingresa su nueva contraseña y el frontend la transmite junto con el token.
    5. El backend valida la vigencia temporal del token, actualiza la contraseña aplicando hash con bcrypt y elimina o invalida el token usado.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Solicitud procesada | 202 | Mensaje informativo: `"If the account exists, a link will be sent shortly"` |
| Cambio completado | 200 | Mensaje informativo: `"Password updated successfully"` |
| Token inválido / caducado | 400 | Mensaje de error: `"Token invalid or expired"` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/v1/auth/forgot-password` | No | Valida el email y envía el token de recuperación |
| POST | `/api/v1/auth/reset-password` | No | Consume el token y aplica la nueva contraseña cifrada |

* **Reglas de negocio:**
    * **RN-004:** Los tokens de recuperación de contraseñas caducan automáticamente tras sesenta (60) minutos de emisión o inmediatamente al consumirse.
