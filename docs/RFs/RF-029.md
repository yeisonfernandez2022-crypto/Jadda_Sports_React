### RF-029 — Actualizar el inventario de manera detallada
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-029 |
| **Nombre** | Actualizar el inventario de manera detallada |
| **Módulo** | Panel de administración / Inventario |
| **Prioridad** | Alta |
| **Estado** | No implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los administradores actualizar el stock de las variantes de producto (talla, color) directamente desde el panel de edición de producto.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `ID_VARIANTE` | Entero | Sí | Identificador de la variante |
| `STOCK` | Entero | Sí | Cantidad disponible, mayor o igual a cero |

* **Proceso:**
    1. El administrador edita el producto y modifica el stock de una variante en el panel `/admin/editar/:id`.
    2. El backend actualiza el campo `STOCK` en la tabla `PRODUCTO_VARIANTES`.
    3. También se registra en `MOVIMIENTOS_STOCK` si es necesario.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Stock actualizado | 200 | Datos de la variante actualizada |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| PUT | `/api/productos/:id/variantes/:idVariante` | Sí (Admin) | Actualiza el stock de una variante específica |
