### RF-029 — Actualizar el inventario de manera detallada
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-029 |
| **Nombre** | Actualizar el inventario de manera detallada |
| **Módulo** | Panel de administración / Inventario |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los administradores registrar variaciones en el stock, ajustando de forma manual las unidades disponibles de cualquier variante (SKU).
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `variant_id` | Entero | Sí | Identificador de la variante de stock a modificar |
| `stock_adjustment` | Entero | Sí | Cantidad entera (valores positivos suman, negativos restan) |

* **Proceso:**
    1. El operador asienta un movimiento de almacén.
    2. El backend arranca una transacción de base de datos (`DB Transaction`), recalcula el valor de la columna `quantity_available` de la tabla `product_stocks` y guarda el movimiento en el registro de auditoría.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Ajuste procesado | 200 | Datos: `{"variant_id": 1, "previous_stock": 5, "new_stock": 12}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/v1/admin/inventory/adjust`| Sí (Admin) | Registra entradas o salidas manuales de existencias de un SKU |

* **Reglas de negocio:**
    * **RN-012:** Toda modificación manual de inventario debe guardar obligatoriamente una traza de auditoría con la estampa de tiempo, la cantidad ajustada y el ID del administrador responsable.
