### RF-029 — Actualizar el inventario de manera detallada
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-029 |
| **Nombre** | Actualizar el inventario de manera detallada |
| **Módulo** | Panel de administración / Inventario |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 (completado 2026-08-13) |

* **Descripción:** Permite a los administradores actualizar el stock de las variantes de producto (talla, color) directamente desde el panel de edición de producto.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `ID_VARIANTE` | Entero | Sí | Identificador de la variante |
| `STOCK` | Entero | Sí | Cantidad disponible, mayor o igual a cero |

* **Proceso:**
    1. El administrador edita el producto y modifica el stock de una variante en el panel `/admin/editar/:id`.
    2. El backend actualiza el campo `STOCK` en la tabla `PRODUCTO_VARIANTES`.
    3. Cada cambio de inventario se registra en `MOVIMIENTOS_STOCK`: entrada/salida por edición manual, salida en cada checkout (decremento real de stock en la transacción) y reingreso al aprobar devoluciones (helper `backend/utils/movimientosStock.js`, nunca bloquea la operación principal).
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Stock actualizado | 200 | Datos de la variante actualizada |

* **Nota de implementación:** El stock se actualiza en `PRODUCTO_VARIANTES` con registro detallado en `MOVIMIENTOS_STOCK` (TIPO_MOVIMIENTO `ENTRADA`/`SALIDA`, CANTIDAD = diferencia o unidades vendidas/devueltas, FECHA = CURDATE()). El checkout decrementa el stock de cada variante dentro de su transacción (`checkoutController.js`); al aprobar una devolución el stock se reingresa y también queda registrado (`devolucionController.js`); si la variante pasa de 0 → >0 al editarla, dispara `notificarReposicion()`.

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| PUT | `/api/productos/variantes/:idVariante` | Sí (Admin) | Actualiza el stock de una variante específica (registra ENTRADA/SALIDA si cambió) |
| POST | `/api/productos/:id/variantes` | Sí (Admin) | Crea una variante (registra ENTRADA si nace con stock > 0) |
