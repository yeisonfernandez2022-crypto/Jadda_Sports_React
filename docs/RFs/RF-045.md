### RF-045 — Subir y cambiar la foto de perfil
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-045 |
| **Nombre** | Foto de perfil |
| **Módulo** | Usuario / Perfil |
| **Prioridad** | Baja |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Permite al usuario autenticado subir una foto de perfil desde su computador (base64, límite 10 MB). El archivo se guarda en `backend/uploads/perfiles/u{ID_USUARIO}/` y queda servida en `/images/perfiles/u{id}/...` (bind-mount a `frontend/public/images/perfiles`). La URL se persiste en `USUARIOS.FOTO_URL` y se usa en Navbar, dropdown y Perfil (avatar con borde rojo + modal de vista en pantalla completa).
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `imagen` | Base64 (Body) | Sí | ≤ 10 MB, imagen válida (jpg/png/webp) |

* **Proceso:**
    1. El usuario hace click en su avatar → menú → "Cargar foto desde el navegador" (input file fuera del menú para que el diálogo abra).
    2. `POST /api/auth/foto` guarda el archivo en la carpeta `u{ID}` del usuario y devuelve la URL.
    3. `PUT /api/auth/perfil` con `foto_url` persiste la ruta y `refreshPerfil()` actualiza el contexto.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Foto subida | 200/201 | `{ foto_url: "/images/perfiles/u..." }` |
| Imagen demasiado grande | 400 | Mensaje de límite 10 MB |
| Sin sesión | 401 | Mensaje de sesión inactiva |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/auth/foto` | Sí | Sube y guarda la foto de perfil en disco |
| PUT | `/api/auth/perfil` | Sí | Persiste `foto_url` en `USUARIOS` |

* **Nota defuncionamiento:** funciona SOLO en Docker (bind-mount `./frontend/public/images/perfiles:/app/uploads/perfiles`).
