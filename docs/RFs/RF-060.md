### RF-060 — Cálculo de costo de envío por ubicación
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-060 |
| **Nombre** | Cálculo de envío |
| **Módulo** | Checkout / Logística |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** El sistema calcula el costo de envío según departamento y ciudad del cliente, con tarifa por departamento (8k-15k) y excepciones por ciudad (40+ ciudades), y envío gratis desde $800.000 (`ENVIO_GRATIS_DESDE`). Normaliza tildes y mayúsculas. Se usa en carrito, checkout y correo.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `departamento` | Texto | Sí | Normalizado (sin tildes) |
| `ciudad` | Texto | No | Si coincide, usa tarifa de ciudad |
| `subtotal` | Número | Sí | Suma de productos con descuentos |

* **Proceso:**
    1. Frontend pide `GET /api/envio/calcular?departamento=&ciudad=&subtotal=` con debounce 400 ms al elegir departamento/ciudad.
    2. `utils/envio.js` resuelve `ciudad → tarifa ciudad` → `departamento → tarifa departamento` → `default 15k`; si `subtotal >= 800000` devuelve `0` y `gratis true`.
    3. Checkout lo suma al total (`subtotal - descuento + costoEnvio`) y lo persiste en `ENVIOS.COSTO_ENVIO`; lo muestra con `BarraEnvioGratis`.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Cálculo ok | 200 | `{ costo, gratis, faltante }` |
| Subtotal supera umbral | 200 | `{ costo:0, gratis:true }` |
| Departamento inválido | 200 | Usa tarifa por defecto 15k |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/envio/calcular` | No | Calcula costo por ubicación y subtotal |

* **Reglas de negocio:**
    * **RN-063:** `ENVIO_GRATIS_DESDE = 800000`; la barra muestra `Te faltan $X` y porcentaje de progreso.
    * **RN-064:** La ciudad tiene prioridad sobre el departamento; se normaliza quitando tildes y pasando a minúsculas.
