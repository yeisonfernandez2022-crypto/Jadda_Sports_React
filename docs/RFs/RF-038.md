### RF-038 — Generar recomendaciones basadas en compras previas del cliente
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-038 |
| **Nombre** | Generar recomendaciones basadas en compras previas del cliente |
| **Módulo** | Analítica / Fidelización |
| **Prioridad** | Baja |
| **Estado** | No implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** El sistema analiza las categorías de los pedidos anteriores de un usuario registrado para sugerirle de forma personalizada artículos similares o complementarios en la portada de la tienda (sección "Recomendados para ti"). Los productos ya comprados se excluyen y el ranking prioriza las categorías más compradas. Si el usuario no tiene compras, se muestran los más vendidos de la tienda como fallback.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `—` | Sesión (Cookie) | Sí | Usuario autenticado |

* **Proceso:**
    1. El frontend (portada, solo con sesión) consulta `GET /api/productos/recomendados`.
    2. El backend obtiene las categorías de las ventas del usuario (excluye CANCELADAS) y selecciona productos de esas categorías que el usuario no haya comprado.
    3. Ordena por frecuencia de compra de la categoría y precio; limita a 8 resultados.
    4. Si no hay resultados (sin compras o todo comprado), cae al ranking de los más vendidos de la tienda (también excluyendo lo comprado).
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Recomendaciones obtenidas | 200 | `{origen: 'categorias' \| 'populares', productos[]}` con ID, nombre, precio, marca, imagen, stock, rating y variante por defecto |
| Sin sesión | 401 | `{error}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/productos/recomendados` | Sí | Obtiene recomendaciones personalizadas para el usuario |
