### RF-038 — Generar recomendaciones basadas en compras previas del cliente
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-038 |
| **Nombre** | Generar recomendaciones basadas en compras previas del cliente |
| **Módulo** | Analítica / Fidelización |
| **Prioridad** | Baja |
| **Estado** | Implementado |
| **Fecha** | Actualizado 30 oct 2026 |

* **Descripción:** El sistema combina 3 señales del usuario registrado para sugerirle de forma personalizada artículos similares en la portada de la tienda (sección "Recomendados para ti") y en la página de favoritos (sección "Recomendados para ti" con "Ver más"): los productos que **ha comprado** (ventas no CANCELADAS), los que marcó como **favoritos** y los que **ha visto** (HISTORIAL). Cada categoría de interés suma su peso (compra ×3, favorito ×2, vista ×1) y el ranking prioriza las categorías con mayor peso acumulado. Se excluyen los productos ya comprados, ya favoritos y ya vistos, y los agotados. Si el usuario no tiene ninguna señal, se muestran los más vendidos de la tienda como fallback.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `—` | Sesión (Cookie) | Sí | Usuario autenticado |
| `limite` | Query | No | Entero 1-24 (default 8); la página de favoritos pide 16 para su sección "Ver más" |

* **Proceso:**
    1. El frontend (portada con sesión, o /favoritos) consulta `GET /api/productos/recomendados?limite=N`.
    2. El backend construye el pool de categorías con los productos comprados, favoritos y vistos del usuario (UNION de las 3 fuentes).
    3. Selecciona productos disponibles de esas categorías, excluyendo ya comprados, ya favoritos y ya vistos.
    4. Ordena por peso de señales de su categoría (3×compras + 2×favoritos + 1×vistas) y precio; limita según `limite`.
    5. Si no hay señales (o no quedan productos disponibles), cae al ranking de los más vendidos de la tienda (también excluyendo lo comprado/favorito/visto).
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Recomendaciones obtenidas | 200 | `{origen: 'senales' \| 'populares', productos[]}` con ID, nombre, precio, marca, imagen, stock, rating y variante por defecto |
| Sin sesión | 401 | `{error}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/productos/recomendados` | Sí | Obtiene recomendaciones personalizadas para el usuario |
