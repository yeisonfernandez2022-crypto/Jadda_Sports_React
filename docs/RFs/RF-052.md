### RF-052 — Gestión del estado de ventas por el vendedor
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-052 |
| **Nombre** | Gestión de envíos del vendedor |
| **Módulo** | Marketplace / Ventas |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** El vendedor administra el ciclo de envío de las ventas que incluyen SUS productos con el mismo stepper del admin (Pendiente→Por empaquetar→Empacado→En camino→Entregado), además del estado de la venta y "Cancelar envío". Al marcar ENTREGADO se registra `FECHA_ENTREGA`; cada cambio notifica al cliente. El administrador ve todas las órdenes pero solo puede gestionar ventas 100% JADDA: en ventas con productos de terceros su panel es de solo lectura (chip morado con la empresa) y el backend rechaza cambios con 403.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `estado_envio` | Enum | Sí | PENDIENTE, POR_EMPAQUETAR, EMPACADO, EN_CAMINO, ENTREGADO, CANCELADO |
| `estado` | Enum | Sí | PENDIENTE, CONFIRMADA, ENVIADA, COMPLETADA, CANCELADA |

* **Proceso:**
    1. `ventasVendedor` devuelve sus ventas con datos de envío y dirección (WHERE EXISTS por sus productos).
    2. `ventaDelVendedor` valida propiedad; 403 si la venta no incluye productos suyos.
    3. Actualización idempotente (`sinCambios`) + `notificarCambioEstado`.
4. `obtenerTodasLasCompras` expone `ES_DE_VENDEDOR`+empresa; `actualizarEstadoEnvio`/`actualizarEstadoCompra` bloquean ventas de terceros.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Vendedor avanza su venta | 200 | Estado actualizado (+notificación) |
| Venta ajena | 403 | "Esta venta no incluye productos tuyos" |
| Admin en venta de vendedor | 403 | "…se gestiona desde la cuenta del vendedor" |

* **Endpoints asociados:**

| Método | Ruta | Auth | Descripción |
| :--- | :--- | :--- | :--- |
| PUT | `/api/vendedor/ventas/:id/envio` | Vendedor | Estado del envío |
| PUT | `/api/vendedor/ventas/:id/estado` | Vendedor | Estado de la venta |
| PUT | `/api/admin/compras/:id/envio` | Admin | Solo ventas JADDA |
