### RF-037 — Compartir productos en redes sociales
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-037 |
| **Nombre** | Compartir productos en redes sociales |
| **Módulo** | Interacción de usuarios |
| **Prioridad** | Baja |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Genera enlaces optimizados e inyecta etiquetas de metadatos Open Graph (`og:title`, `og:image`, `og:price`) en el servidor para que los productos compartidos en redes sociales se visualicen correctamente con su foto y precio.
* **Proceso:** El frontend genera dinámicamente las URLs de redirección a las APIs de compartición externa de Facebook, X o WhatsApp basándose en las etiquetas meta generadas por el servidor.
