### RF-011 — Mostrar la disponibilidad de los productos en inventario
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-011 |
| **Nombre** | Mostrar la disponibilidad de los productos en inventario |
| **Módulo** | Catálogo de productos / Inventario |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Comunica en tiempo real al usuario el stock de unidades físicas disponibles desglosado por cada una de las variantes particulares del producto para bloquear compras sin existencias.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `id` | Entero (Path) | Sí | Parámetro de ruta correspondiente al ID del producto |

* **Proceso:**
    1. Al cargar los detalles del producto, el frontend llama al servicio de inventario.
    2. El backend interroga la tabla `product_variants` filtrando por el ID del producto y mapeando las columnas `quantity_available` asociadas a cada SKU.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Stock consultado | 200 | Estructura JSON: `{"product_id": 10, "variants": [{"sku": "ZAP-40-BL", "stock": 5}]}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/v1/products/{id}/stock` | No | Devuelve la matriz de existencias actuales agrupadas por SKU variante |
