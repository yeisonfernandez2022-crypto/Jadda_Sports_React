### RF-011 — Mostrar la disponibilidad de los productos en inventario
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-011 |
| **Nombre** | Mostrar la disponibilidad de los productos en inventario |
| **Módulo** | Catálogo de productos / Inventario |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Comunica al usuario el stock de unidades disponibles desglosado por cada variante del producto (color, talla).
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `id` | Entero (Path) | Sí | ID del producto a consultar |

* **Proceso:**
    1. Al cargar los detalles del producto, el frontend llama a `/api/productos/:id/variantes`.
    2. El backend consulta la tabla `PRODUCTO_VARIANTES` filtrando por el ID del producto y devuelve color, talla y stock de cada variante.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Stock consultado | 200 | Lista de variantes con `COLOR`, `TALLA` y `STOCK` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/productos/:id/variantes` | No | Devuelve las variantes con stock disponible |
