### RF-028 — Gestionar los productos del catálogo
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-028 |
| **Nombre** | Gestionar los productos del catálogo |
| **Módulo** | Panel de administración |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite al equipo administrador realizar la gestión de los artículos deportivos del catálogo (crear nuevos productos, corregir datos o deshabilitarlos).
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `name` | Texto | Sí | Título comercial único, máximo 255 caracteres |
| `price` | Decimal | Sí | Valor numérico monetario estrictamente mayor a cero |
| `category_id` | Entero | Sí | Llave foránea que debe enlazar a una categoría válida |

* **Proceso:**
    1. El operador administrativo rellena la ficha del producto en el panel de control.
    2. El backend autentica los permisos del administrador y comprueba las claves foráneas de marcas y categorías.
    3. Realiza la escritura en la tabla `products` y activa las variaciones por defecto del artículo.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Producto registrado | 201 | Objeto JSON detallado con los datos del nuevo producto creado |
| Error en dependencias | 422 | Fallo debido a IDs de marcas o categorías inexistentes |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/v1/admin/products` | Sí (Admin) | Indexa un nuevo producto al catálogo de la plataforma |
| PUT | `/api/v1/admin/products/{id}`| Sí (Admin) | Modifica la información técnica y comercial de un producto |
| DELETE| `/api/v1/admin/products/{id}`| Sí (Admin) | Cambia el estado para ocultar el producto del catálogo de venta |
