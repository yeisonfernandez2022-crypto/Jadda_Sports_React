### RF-028 — Gestionar los productos del catálogo
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-028 |
| **Nombre** | Gestionar los productos del catálogo |
| **Módulo** | Panel de administración |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite al equipo administrador realizar la gestión de los artículos deportivos del catálogo (crear nuevos productos, editar datos o eliminarlos).
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `NOMBRE` | Texto | Sí | Título del producto, máximo 255 caracteres |
| `PRECIO` | Decimal | Sí | Valor numérico mayor a cero |
| `ID_CATEGORIA` | Entero | Sí | Debe enlazar a una categoría válida |
| `MARCA` | Texto | Sí | Marca del producto |
| `ID_PROVEEDOR` | Entero | Sí | Debe enlazar a un proveedor válido |
| `DESCRIPCION` | Texto | No | Descripción del producto |
| `ID_DESCUENTO` | Entero | No | Cupón de descuento opcional |

* **Proceso:**
    1. El administrador gestiona los productos desde `/admin`.
    2. El backend autentica los permisos del administrador.
    3. Crea, actualiza o elimina el registro en la tabla `PRODUCTOS`.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Producto registrado | 201 | Objeto JSON con los datos del nuevo producto |
| Producto actualizado | 200 | Objeto JSON con los datos actualizados |
| Producto eliminado | 200 | Mensaje de confirmación |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/productos` | Sí (Admin) | Crea un nuevo producto |
| PUT | `/api/productos/:id` | Sí (Admin) | Actualiza un producto existente |
| DELETE | `/api/productos/:id` | Sí (Admin) | Elimina un producto |
