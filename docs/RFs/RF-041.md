### RF-041 — Generar y llevar un plan de entrenamiento
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-041 |
| **Nombre** | Plan de entrenamiento |
| **Módulo** | Fidelización / Planes |
| **Prioridad** | Baja |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Genera un plan de entrenamiento personalizado a partir del perfil del usuario autenticado y permite marcar los días completados. El progreso se persiste en el servidor (`backend/data/planes-progreso.json`) y se restaura al volver.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| — | Sesión (cookie) | Sí | Usuario autenticado |
| `id_plan` | Entero (Path) | Sí | Plan del propio usuario |

* **Proceso:**
    1. El usuario consulta `GET /api/planes` → si no tiene plan, crea uno con `POST /api/planes/generar`.
    2. Cada día completado se marca con `POST /api/planes/marcar-dia/:id_plan`.
    3. `misPlanes` devuelve `DIAS_COMPLETADOS` calculado del archivo de progreso persistido.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Planes del usuario | 200 | Lista de planes con días completados |
| Plan generado | 200/201 | Plan creado (con `dias_completados`) |
| Día marcado | 200 | `{ ok, dias_completados }` actualizado |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/planes` | Sí | Planes del usuario |
| POST | `/api/planes/generar` | Sí | Genera un plan nuevo |
| POST | `/api/planes/marcar-dia/:id_plan` | Sí | Marca un día como completado |
