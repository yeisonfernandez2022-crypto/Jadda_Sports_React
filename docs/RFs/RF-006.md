### RF-006 — Mostrar el catálogo de productos disponibles
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-006 |
| **Nombre** | Mostrar el catálogo de productos disponibles |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Presenta de manera visual al cliente el listado general con todos los productos deportivos aptos para la venta, aplicando paginación desde el servidor para optimizar los tiempos de carga en red.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `page` | Entero (Query) | No | Valor superior a 0, por defecto: 1 |
| `limit` | Entero (Query) | No | Valor máximo admitido: 100, por defecto: 20 |

* **Proceso:**
    1. El cliente entra en el catálogo o hace scroll en la vista.
    2. El backend realiza una consulta paginada a la base de datos limitando los resultados (`LIMIT` / `OFFSET`) y filtrando exclusivamente las entidades donde `is_active = true`.
    3. El sistema cuenta el total general de ítems activos de la consulta y mapea el listado simplificado de productos.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Obtención exitosa | 200 | Estructura JSON: `{"items": [...], "page": 1, "limit": 20, "total_items": 120}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/v1/products` | No | Lista los productos activos empleando paginación de servidor |
