### RF-044 — Iniciar sesión con redes sociales (Google)
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-044 |
| **Nombre** | Login social |
| **Módulo** | Autenticación |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Permite autenticarse mediante OAuth 2.0 con Google (Passport.js). Si el usuario no existía, se crea automáticamente con rol cliente (4) y cuenta confirmada; si ya existe, se vincula la sesión. El callback redirige a `http://localhost:5173` con `?user=...&photo=...` que el frontend procesa en `OAuthPopupCallback.tsx`.
* **Entradas:** Ninguna directa. Delegado al proveedor OAuth (token acces).
* **Proceso:**
    1. El usuario pulsa "Google" en el modal de login → `GET /api/auth/google` (popup).
    2. Passport autentica contra Google; en el callback se crea o actualiza `USUARIOS` (la contraseña se guarda como `'google'` como marcador del método). La estrategia web valida el perfil vía `openidconnect.googleapis.com/v1/userinfo` exigiendo `email_verified`.
    3. El popup emite `postMessage` con `oauth-success` y `AuthContext` refresca el perfil.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Autenticación correcta | Redirect 302 | Redirige con `?user=...&photo=...` |
| Correo sin verificar en Google | — | Error "El correo de Google no está verificado" (no se crea cuenta) |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/auth/google`, `/api/auth/google/callback` | No | OAuth Google 2.0 |
| POST | `/api/auth/social-login` | No | Inicio de sesión directo con datos del proveedor (app móvil) |

* **Nota de implementación:** Requiere `GOOGLE_CLIENT_ID/SECRET` en `.env`; sin credenciales el backend responde 503 "Login con Google no está configurado en este servidor".
