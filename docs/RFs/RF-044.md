### RF-044 — Iniciar sesión con redes sociales (Google y Facebook)
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-044 |
| **Nombre** | Login social |
| **Módulo** | Autenticación |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Permite autenticarse mediante OAuth 2.0 con Facebook o Google (Passport.js). Si el usuario no existía, se crea automáticamente con rol cliente (4) y cuenta confirmada; si ya existe, se vincula la sesión. El callback redirige a `http://localhost:5173` con `?user=...&photo=...` que el frontend procesa en `OAuthPopupCallback.tsx`.
* **Entradas:** Ninguna directa. Delegado al proveedor OAuth (token acces).
* **Proceso:**
    1. El usuario pulsa "Google" o "Facebook" en el modal de login → `GET /api/auth/google` o `/facebook` (popup).
    2. Passport autentica contra el proveedor; en el callback se crea o actualiza `USUARIOS` (la contraseña se guarda como `'google'`/`'facebook'` como marcador del método).
    3. El popup emite `postMessage` con `oauth-success` y `AuthContext` refresca el perfil.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Autenticación correcta | Redirect 302 | Redirige con `?user=...&photo=...` |
| Facebook sin email | — | Error "Facebook no proporcionó email" (no se crea cuenta) |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/auth/google`, `/api/auth/google/callback` | No | OAuth Google 2.0 |
| GET | `/api/auth/facebook`, `/api/auth/facebook/callback` | No | OAuth Facebook |
| POST | `/api/auth/social-login` | No | Inicio de sesión directo con datos del proveedor (fallback) |

* **Nota de implementación:** Requiere `GOOGLE_CLIENT_ID/SECRET` y `FACEBOOK_CLIENT_ID/SECRET` en `.env`; sin credenciales el proveedor no responde.
