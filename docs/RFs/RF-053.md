### RF-053 — Reportes de ventas del vendedor con descargas
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-053 |
| **Nombre** | Reportes del vendedor |
| **Módulo** | Marketplace / Reportes |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Página `/vendedor/reportes` con rango de fechas (presets 7/30/90 días): KPIs (ingresos propios, pedidos, unidades, ticket promedio), gráfica diaria y ranking de sus productos más vendidos con stock. Descargable en Excel (hojas Ventas/Resumen con fórmulas COUNTIFS+SUMIFS/MasVendidos/Serie) y PDF ejecutivo (KPI cards, barras diarias, tabla top). Ingresos = SUMA de los subtotales de SUS renglones, excluyendo ventas canceladas.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `desde`, `hasta` | Fecha ISO | No | Default últimos 30 días |

* **Proceso:** `reporteVendedorDatos.js` concentra las consultas filtradas por `p.ID_VENDEDOR`; `reporteVendedorExcel.js` (exceljs) y `reporteVendedorPdf.js` (pdfkit) generan los archivos que se descargan como blob desde la UI.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Datos del reporte | 200 | Resumen + serie + más vendidos |
| Excel/PDF | 200 | Binario con Content-Disposition |
| Sin sesión / no vendedor | 401/403 | Error |

* **Endpoints asociados:**

| Método | Ruta | Auth | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/vendedor/reportes` | Vendedor | Datos del reporte |
| GET | `/api/vendedor/reportes/excel` | Vendedor | Descarga .xlsx |
| GET | `/api/vendedor/reportes/pdf` | Vendedor | Descarga .pdf |
