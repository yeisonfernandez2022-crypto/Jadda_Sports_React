### RF-049 — Recordar y mostrar el historial de navegación del usuario
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-049 |
| **Nombre** | Historial de navegación |
| **Módulo** | Usuario / Personalización |
| **Prioridad** | Baja |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Registra los productos que el usuario visita y los muestra en la portada como "Recientemente vistos", con descuento y stock ("AGOTADO"/"Solo quedan X"). Con sesión se persiste en el servidor (`/api/historial`); sin sesión, en `localStorage`. La entrada guarda `ID_DESCUENTO`, `STOCK` e `ID_VARIANTE_POR_DEFECTO` para el render completo en `Principal`.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `ID_PRODUCTO` | Entero (Body) | Sí | Producto existente |
| `ID_DESCUENTO`, `STOCK`, `ID_VARIANTE_POR_DEFECTO` | Mixtos | No | Campos enriquecidos para la tarjeta |

* **Proceso:**
    1. `ProductDetailPage` guarda la vista (localStorage siempre; `POST /api/historial` si hay sesión).
    2. `Principal` llama a `GET /api/historial` (o lee localStorage) y enriquece cada ítem con los datos completos de producto para mostar descuento/badge.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Historial obtenido | 200 | Lista de productos vistos recientemente |
| Entrada guardada | 200/201 | Confirmación |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/historial` | Sí | Obtiene el historial de navegación del usuario |
| POST | `/api/historial` | Sí | Registra la visita a un producto |
