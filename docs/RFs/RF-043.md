### RF-043 — Notificaciones in-app (campana de avisos)
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-043 |
| **Nombre** | Notificaciones in-app |
| **Módulo** | Usuario / Notificaciones |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Proporciona un centro de notificaciones dentro de la app (campana): lista de avisos con estado leído/no leído, contador de no leídas y marcado individual o masivo como leídas. Las notificaciones se crean por eventos del sistema (cambio de estado de pedido, devolución procesada, aviso de reposición de stock).
* **Entradas:** Ninguna. Usuario autenticado (sesión).
* **Proceso:**
    1. El backend crea filas en `NOTIFICACIONES` con tipo y ruta destino (p. ej. `/perfil/compras`) usando `crearNotificacion` (helper compartido).
    2. El frontend consulta `GET /api/notificaciones` y el contador de `no-leidas` para el badge de la campana.
    3. El usuario marca leídas individualmente o en bloque.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Notificaciones listadas | 200 | Lista ordenada por fecha, con LEIDA |
| Contador no leídas | 200 | `{ total }` |
| Marcada leída | 200 | Confirmación |
| Todas leídas | 200 | Confirmación |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/notificaciones` | Sí | Notificaciones del usuario |
| GET | `/api/notificaciones/no-leidas` | Sí | Cantidad de notificaciones sin leer |
| POST | `/api/notificaciones/:id/leida` | Sí | Marca una notificación como leída |
| POST | `/api/notificaciones/leer-todas` | Sí | Marca todas como leídas |
