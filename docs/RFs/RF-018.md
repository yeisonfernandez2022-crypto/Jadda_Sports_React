### RF-018 — Seleccionar el método de pago
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-018 |
| **Nombre** | Seleccionar el método de pago |
| **Módulo** | Checkout / Pasarela de pagos |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite al comprador definir la modalidad transaccional (tarjeta, Stripe, MercadoPago, transferencia) con la que pretende saldar la deuda comercial del pedido.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `payment_method` | Texto | Sí | Valores enumerados válidos (`"stripe"`, `"mercadopago"`, `"bank"`) |

* **Proceso:**
    1. El comprador escoge su opción preferida en el formulario.
    2. El backend recibe el método e inicializa los parámetros de sesión contra la pasarela seleccionada, devolviendo los tokens o preferencias de checkout necesarios.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Método seleccionado | 200 | JSON: `{"payment_method": "stripe", "checkout_session_id": "cs_test_..."}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/v1/checkout/payment-method`| Sí | Configura la vía de pago e interactúa con pasarelas externas |
