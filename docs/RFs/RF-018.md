### RF-018 — Seleccionar el método de pago
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-018 |
| **Nombre** | Seleccionar el método de pago |
| **Módulo** | Checkout / Pasarela de pagos |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite al comprador seleccionar entre métodos de pago disponibles: Tarjeta crédito/débito, PSE, Nequi o Daviplata.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `metodoPago` | Texto | Sí | Valores: `"tarjeta"`, `"pse"`, `"nequi"`, `"daviplata"` |

* **Proceso:**
    1. El comprador escoge su opción preferida en el formulario de checkout.
    2. El frontend captura los datos específicos según el método (número de tarjeta, correo Nequi, etc.).
    3. El backend procesa el pago mediante el endpoint de checkout.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Pago procesado | 201 | Redirección a página de confirmación |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/checkout/procesar` | Sí | Procesa el pago completo con dirección, método y productos |
| GET | `/api/usuarios/metodos-pago` | Sí | Lista de métodos de pago guardados del usuario |
