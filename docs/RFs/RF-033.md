### RF-033 — Gestionar devoluciones de productos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-033 |
| **Nombre** | Gestionar devoluciones de productos |
| **Módulo** | Panel de administración / Postventa |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los administradores revisar, aprobar o rechazar las solicitudes de devolución de productos enviadas por los clientes, automatizando el reingreso al stock y la orden de reembolso.
* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/admin/devoluciones/:id/procesar`| Sí (Admin) | Procesa una devolución y gestiona el dinero y el stock |
