### RF-033 — Gestionar devoluciones de productos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-033 |
| **Nombre** | Gestionar devoluciones de productos |
| **Módulo** | Panel de administración / Postventa |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los clientes solicitar la devolución de productos de pedidos completados y a los administradores revisar, aprobar o rechazar esas solicitudes desde el panel. Al aprobar se reingresa automáticamente la cantidad devuelta al stock de la variante por defecto del producto y se notifica al cliente por campana in-app; el reembolso se gestiona por el método de pago original.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `id_venta` | Entero (Body) | Sí | Venta COMPLETADA del propio usuario |
| `id_producto` | Entero (Body) | Sí | Debe estar en el detalle de la venta |
| `cantidad` | Entero (Body) | Sí | ≥ 1 y ≤ comprado − ya solicitado/aprobado |
| `motivo` | Texto (Body) | No | Máx 500 caracteres |
| `estado` | Texto (Body, admin) | Sí | `APROBADA` o `RECHAZADA` |

* **Proceso:**
    1. El cliente solicita la devolución desde "Mis Compras" (botón Devolver en cada producto de un pedido COMPLETADO).
    2. El backend valida venta, propiedad, estado y cantidades; inserta la solicitud con ESTADO `SOLICITADA`.
    3. El admin revisa la solicitud en `/admin/devoluciones` y la aprueba o rechaza.
    4. Al aprobar, el backend (transacción) reingresa la cantidad al stock de la variante por defecto del producto, marca la solicitud y crea una notificación in-app para el cliente.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Solicitud creada | 201 | `{ok, msg, ID_DEVOLUCION}` |
| Lista del usuario | 200 | Devoluciones con producto e imagen |
| Lista admin | 200 | Devoluciones con cliente, producto y total de la venta |
| Devolución procesada | 200 | `{ok, msg}` |
| Ventas no COMPLETADAS / cantidad inválida | 400 | `{ok: false, msg}` |
| Venta inexistente o de otro usuario | 404 | `{ok: false, msg}` |
| Solicitud ya procesada | 400 | `{ok: false, msg}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/devoluciones` | Sesión | Cliente crea una solicitud de devolución |
| GET | `/api/devoluciones` | Sesión | Lista las solicitudes del usuario |
| GET | `/api/devoluciones/admin` | Admin | Lista todas las solicitudes |
| POST | `/api/admin/devoluciones/:id/procesar` | Admin | Aprueba (reingresa stock) o rechaza |
