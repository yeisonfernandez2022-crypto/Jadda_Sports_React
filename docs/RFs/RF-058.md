### RF-058 — Administración de usuarios
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-058 |
| **Nombre** | Administración de usuarios |
| **Módulo** | Administración / Usuarios |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** El administrador lista en `/admin/usuarios` todos los usuarios con buscador y ve el detalle completo en modal `au-modal`: avatar, rol, verificación, estadísticas (para comprador: compras/gastado/favoritos/retos; para vendedor: artículos/unidades/ventas/ingresos), información personal, direcciones, métodos de pago, y si es vendedor la empresa y sus ventas. Incluye grupos colapsables para compras y retos con filtros y paginación.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `q` (buscador) | Texto | No | Filtra por usuario/nombre/correo en cliente |
| `id_usuario` | Entero | Sí (detalle) | Existe en `USUARIOS` |

* **Proceso:**
    1. `GET /api/admin/usuarios` devuelve `USUARIOS JOIN ROLES` ordenado por registro.
    2. `GET /api/admin/usuarios/:id` arma `usuario + direcciones + USUARIOS_METODOS_PAGO JOIN METODOS_PAGO + stats (compras/gastado/favoritos/retos)`; si `ID_ROL=6` añade `VENDEDORES + stats de ventas (productos/unidades/ventas/ingresos)` y `ventas` recientes y `compras`/`retos` limit 200.
    3. Frontend muestra hero, stats y secciones `Direcciones`, `Métodos de pago`, `Información de la empresa` (vendedor) y `Registro de ventas`.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Lista ok | 200 | Array de usuarios |
| Detalle ok | 200 | `{ usuario, direcciones, metodos, stats, vendedor, ventas }` |
| No existe | 404 | "Usuario no encontrado" |
| No admin | 403 | "No autorizado" |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/admin/usuarios` | Sí (admin) | Lista usuarios |
| GET | `/api/admin/usuarios/:id` | Sí (admin) | Detalle completo |

* **Reglas de negocio:**
    * **RN-060:** El detalle distingue comprador vs vendedor por `ID_ROL=6`; el vendedor ve métricas de ventas, el comprador ve gastado/favoritos.
