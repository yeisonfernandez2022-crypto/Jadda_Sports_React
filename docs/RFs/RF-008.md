### RF-008 — Ordenar los productos por precio
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-008 |
| **Nombre** | Ordenar los productos por precio |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Proporciona los mecanismos para ordenar los productos devueltos en la consulta según el precio, admitiendo secuencias tanto de menor a mayor como viceversa.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `orden` | Texto (Query) | No | Valores: `"asc"` o `"desc"` |

* **Proceso:**
    1. El usuario selecciona un criterio de ordenamiento en el frontend.
    2. El frontend realiza la petición a la API con el parámetro de orden.
    3. El backend ordena los resultados por precio ascendente o descendente.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Ordenación exitosa | 200 | Lista de productos ordenados por precio |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/productos` | No | Procesa el orden de la lista con el argumento `orden` |
