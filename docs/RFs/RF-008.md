### RF-008 — Ordenar los productos por precio
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-008 |
| **Nombre** | Ordenar los productos por precio |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Proporciona los mecanismos para ordenar los productos devueltos en la consulta según el precio, admitiendo secuencias tanto de menor a mayor como viceversa.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `sort_by` | Texto (Query) | No | Valor admitido fijo: `"price"` |
| `order` | Texto (Query) | No | Valores admitidos exactos: `"asc"`, `"desc"` |

* **Proceso:**
    1. El usuario modifica el selector de ordenamiento de la vista.
    2. El backend captura los parámetros de ordenamiento.
    3. Se inyecta la instrucción `ORDER BY price ASC` u `ORDER BY price DESC` dentro de la sintaxis de consulta SQL.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Ordenación exitosa | 200 | Set estructurado de productos dispuestos en el orden económico solicitado |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/v1/products` | No | Procesa el orden de la lista final con los argumentos `sort_by` y `order` |
