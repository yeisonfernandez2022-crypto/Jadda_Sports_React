### RF-004 — Actualización de datos personales
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-004 |
| **Nombre** | Actualización de datos personales |
| **Módulo** | Perfil de usuario |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los clientes registrados modificar la información editable de su perfil personal y de contacto almacenada en el sistema.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `nombre` | Texto | No | Opcional, de 2 a 255 caracteres |
| `apellido` | Texto | No | Apellido del usuario |
| `usuario` | Texto | No | Nombre de usuario único |
| `telefono` | Texto | No | Formato numérico de teléfono |
| `tipo_documento` | Texto | No | Tipo de identificación |
| `numero_documento` | Texto | No | Número de identificación |
| `foto_url` | Texto | No | URL de avatar |

* **Proceso:**
    1. El usuario accede a su perfil y edita los campos disponibles.
    2. El backend identifica al usuario por su sesión de Passport.
    3. El sistema actualiza los registros en la tabla `USUARIOS`.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Actualización exitosa | 200 | Objeto JSON con los datos actualizados del perfil |
| Falta autenticación | 401 | Mensaje de error: `"No hay sesión activa en el servidor"` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/auth/perfil` | Sí | Obtiene los datos del perfil del usuario autenticado |
| PUT | `/api/auth/perfil` | Sí | Actualiza los datos editables del perfil |
