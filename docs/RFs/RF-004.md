### RF-004 — Actualización de datos personales
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-004 |
| **Nombre** | Actualización de datos personales |
| **Módulo** | Perfil de usuario |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los clientes registrados modificar la información editable de su perfil personal y de contacto almacenada en el sistema.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `full_name` | Texto | No | Opcional, de 2 a 255 caracteres |
| `phone` | Texto | No | Formato numérico de teléfono internacional válido |
| `address` | Texto | No | Línea de dirección de correspondencia física |

* **Proceso:**
    1. El usuario accede al módulo de configuración de cuenta con una sesión JWT válida.
    2. El usuario edita uno o más campos disponibles en el formulario y pulsa guardar.
    3. El backend intercepta el payload JSON y extrae el ID de usuario desde los claims del token.
    4. El sistema valida los formatos e inserta los nuevos valores dentro de la fila de la entidad `users`.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Actualización exitosa | 200 | Objeto JSON con los datos actualizados del perfil |
| Falta autenticación | 401 | Mensaje de error: `"Could not validate credentials"` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| PUT | `/api/v1/users/profile` | Sí | Sobreescribe la información editable del perfil |
