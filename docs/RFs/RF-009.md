### RF-009 — Buscar productos por nombre o palabra clave
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-009 |
| **Nombre** | Buscar productos por nombre o palabra clave |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Habilita una barra de texto para indexar y buscar ítems específicos del catálogo evaluando el término introducido contra nombres, tags o descripciones de productos.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `search` | Texto (Query) | Sí | Cadena limpia de texto, mínimo de 3 caracteres de longitud |

* **Proceso:**
    1. El usuario tipea un término en el cuadro de búsqueda.
    2. El backend procesa el string de entrada y ejecuta un filtrado insensible a mayúsculas/minúsculas usando comodines (`ILIKE %search%`) sobre las columnas indexadas de las tablas de productos.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Coincidencias halladas | 200 | Lista de productos parciales que contienen el patrón de búsqueda |
| Entrada insuficiente | 422 | Mensaje descriptivo de error de validación en longitud de caracteres |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/v1/products` | No | Realiza búsquedas de productos mediante el argumento query `search` |
