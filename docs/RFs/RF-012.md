### RF-012 — Mostrar productos relacionados o recomendados
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-012 |
| **Nombre** | Mostrar productos relacionados o recomendados |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Baja |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Ofrece una sección de sugerencias cruzadas mostrando un carrusel de hasta cuatro (4) productos adicionales que compartan categorías o marcas con el artículo visualizado.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `id` | Entero (Path) | Sí | ID de referencia del producto en visualización |

* **Proceso:**
    1. El backend detecta la categoría del producto actual.
    2. Ejecuta una consulta extrayendo productos alternativos bajo la misma categoría, excluyendo el ID del producto consultado, ordenando por volumen de ventas y aplicando un `LIMIT 4`.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Recomendación hecha | 200 | Arreglo JSON simplificado conteniendo los datos de los 4 artículos recomendados |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/v1/products/{id}/related` | No | Resuelve y entrega las sugerencias comerciales recomendadas para el ítem |
