### RF-012 — Mostrar productos relacionados o recomendados
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-012 |
| **Nombre** | Mostrar productos relacionados o recomendados |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Baja |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Ofrece una sección de sugerencias mostrando hasta cuatro (4) productos adicionales que compartan categoría con el artículo visualizado, ordenados aleatoriamente.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `id` | Entero (Path) | Sí | ID del producto actual |

* **Proceso:**
    1. El backend detecta la categoría del producto actual.
    2. Ejecuta `SELECT` con `ORDER BY RAND()` y `LIMIT 4` en la misma categoría, excluyendo el producto actual.
    3. Si hay menos de 4 productos en la misma categoría, se toman de otras categorías como fallback.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Recomendación hecha | 200 | Lista JSON con hasta 4 productos recomendados |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/productos/relacionados/:id` | No | Devuelve productos relacionados |
