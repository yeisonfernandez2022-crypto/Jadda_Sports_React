### RF-016 — Aplicar cupones de descuento
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-016 |
| **Nombre** | Aplicar cupones de descuento |
| **Módulo** | Carrito de compras / Promociones |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Modifica los totales económicos del carrito aplicando beneficios porcentuales o montos fijos condicionados al ingreso de un código alfanumérico promocional válido.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `coupon_code` | Texto (Body) | Sí | Alfanumérico limpio, coincidente con registros en DB |

* **Proceso:**
    1. El usuario introduce el string del código promocional in el checkout.
    2. El backend consulta la tabla `coupons` confirmando que la fecha actual esté dentro de la vigencia, que el cupón esté activo y que el subtotal del carrito supere el mínimo exigido.
    3. Deduce el valor correspondiente y recalcula el resumen.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Cupón aplicado | 200 | Datos actualizados: `{"success": true, "discount": 10.0, "new_total": 114.0}` |
| Cupón inválido / vencido| 400 | Mensaje de error: `"Coupon code is invalid, expired, or condition unmet"` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/v1/cart/apply-coupon` | Opcional | Valida e inyecta los efectos de descuento de un cupón al carrito |

* **Reglas de negocio:**
    * **RN-008:** No se permite el uso acumulativo de múltiples cupones promocionales dentro de una misma orden de compra.
