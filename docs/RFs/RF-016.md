### RF-016 — Aplicar cupones de descuento
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-016 |
| **Nombre** | Aplicar cupones de descuento |
| **Módulo** | Carrito de compras / Promociones |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Modifica los totales económicos del carrito aplicando beneficios porcentuales condicionados al ingreso de un código promocional válido.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `codigo` | Texto (Body) | Sí | Debe coincidir con un código en la tabla `DESCUENTOS` |

* **Proceso:**
    1. El usuario introduce el código promocional en el checkout.
    2. El backend consulta la tabla `DESCUENTOS` confirmando que la fecha actual esté dentro de la vigencia (`FECHA_INICIO` / `FECHA_FIN`).
    3. Retorna el porcentaje de descuento para que el frontend recalcule el total.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Cupón aplicado | 200 | `{"valido": true, "porcentaje": 10, "descripcion": "JADDA10"}` |
| Cupón inválido / vencido| 400 | Mensaje de error: `"Cupón inválido o vencido"` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/cupones/validar` | Sí | Valida un código de descuento y devuelve el porcentaje |

* **Reglas de negocio:**
    * **RN-008:** No se permite el uso acumulativo de múltiples cupones promocionales dentro de una misma orden de compra.
