### RF-055 — Bloqueo de compras para cuentas de vendedor
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-055 |
| **Nombre** | Vendedores no compran |
| **Módulo** | Marketplace / Reglas |
| **Prioridad** | Baja |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Las cuentas con rol vendedor (ID_ROL=6) no pueden comprar en la tienda: los botones de carrito se ven deshabilitados (opacity reducida, cursor not-allowed y tooltip explicativo) y al hacer click muestran el mensaje "Los vendedores no pueden comprar en la tienda". El backend lo refuerza en `carrito/agregar` y `checkout/procesar` con 403. La app móvil muestra una alerta equivalente desde su CartContext.
* **Proceso:** guard central en `CartContext.addToCart` (web) y móvil + validaciones servidor.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Vendedor agrega al carrito | 403 | Mensaje explicativo |
| Checkout de vendedor | 403 | Mensaje explicativo |
