### RF-039 — Contactar al soporte desde la plataforma
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-039 |
| **Nombre** | Contactar al soporte desde la plataforma |
| **Módulo** | Soporte técnico / Tickets |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los usuarios enviar consultas, quejas o problemas técnicos rellenando un formulario seguro que genera un ticket de atención numerado para el equipo de soporte.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `subject` | Texto (Body) | Sí | Título del problema, longitud máxima de 100 caracteres |
| `message` | Texto (Body) | Sí | Descripción detallada de la incidencia enviada |

* **Proceso:**
    1. El usuario envía el formulario desde la sección de soporte.
    2. El backend asocia el ID del usuario al ticket, escribe el registro en la tabla `support_tickets` con estado inicial `open` y genera un ID secuencial automático.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Ticket abierto | 201 | Confirmación: `{"ticket_id": 140, "status": "open", "message": "Ticket created"}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/v1/support/tickets` | Sí | Registra una nueva solicitud de asistencia en el sistema de atención |
