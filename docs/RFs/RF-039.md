### RF-039 — Contactar al soporte desde la plataforma
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-039 |
| **Nombre** | Contactar al soporte desde la plataforma |
| **Módulo** | Soporte técnico / Tickets |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los usuarios enviar consultas, quejas o problemas técnicos mediante un formulario tipo PQR (Peticiones, Quejas, Reclamos).
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `tipo` | Texto (Body) | Sí | Valores: `"Petición"`, `"Queja"`, `"Reclamo"`, `"Sugerencia"` |
| `asunto` | Texto (Body) | Sí | Título del problema, máximo 255 caracteres |
| `descripcion` | Texto (Body) | Sí | Descripción detallada de la incidencia |
| `numero_pedido` | Texto (Body) | No | Número de pedido relacionado (opcional) |

* **Proceso:**
    1. El usuario llena el formulario PQR desde `/pqr`.
    2. El backend asocia el ID del usuario al PQR, escribe el registro en la tabla `PQR` con estado inicial `PENDIENTE`.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| PQR creado | 201 | Mensaje: `"PQR creada correctamente"` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/pqr` | Sí | Registra una nueva PQR en el sistema |
