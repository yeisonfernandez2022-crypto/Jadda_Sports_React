### RF-040 — Participar en retos deportivos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-040 |
| **Nombre** | Participar en retos deportivos |
| **Módulo** | Gamificación / Retos |
| **Prioridad** | Baja |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Permite al usuario autenticado unirse a retos deportivos, reportar avances (con o sin material de evidencia — imagen o video) y acumular progreso hacia una meta. Si la evidencia requiere revisión, el administrador la aprueba o rechaza. Al completar la meta se genera automáticamente un cupón de descuento `RETO-XXXX-XXXX` de un solo uso con 30 días de vigencia.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `id_reto` | Entero (Path) | Sí | ID del reto existente |
| `cantidad` | Entero (Body) | Sí | Avance a reportar, mayor a 0 |
| `material` | Base64 (Body) | No | Imagen o video ≤ 10 MB (queda PENDIENTE hasta aprobación admin) |
| `tipo` | Texto (Body) | Condicional | `"imagen"` o `"video"` si hay material |

* **Proceso:**
    1. El usuario se une al reto (`POST /api/retos/unirse/:id`).
    2. Reporta su avance desde `Retos.tsx`: sin material suma directo a `CANTIDAD`; con material queda `pendiente` en `RETO_EVIDENCIAS`.
    3. El admin aprueba o rechaza desde `AdminRetos.tsx`; al aprobar suma la cantidad y, al alcanzar META, genera del cupón `RETO-XXXX-XXXX` (30 días, `USADO = 0`).
    4. El cupón se consume en el checkout (marcado `USADO = 1` dentro de la transacción).
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Avance sin material | 200 | Progreso acumulado actualizado |
| Avance con material | 200 | `"Avance pendiente de revisión"` (estado `pendiente`) |
| Evidencia aprobada | 200 | Cantidad sumada + cupón si llegó a meta |
| Evidencia rechazada | 200 | Estado `rechazado`, sin suma |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/retos` | Sí | Lista los retos disponibles |
| GET | `/api/retos/mis-retos` | Sí | Retos del usuario con progreso |
| POST | `/api/retos/unirse/:id` | Sí | El usuario se une a un reto |
| POST | `/api/retos/evidencias/:id_reto_usuario` | Sí | Reporta progreso (con/sin material) |
| GET | `/api/retos/evidencias/:id_reto_usuario` | Sí | Evidencias propias |
| GET/POST | `/api/retos/admin/evidencias*` | Admin | Revisión y aprobación/rechazo |

* **Reglas de negocio:**
    * **RN-011:** Los cupones generados por retos son de un solo uso (`DESCUENTOS.USADO`).
