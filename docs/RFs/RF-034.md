### RF-034 — Consultar estadísticas de productos más vendidos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-034 |
| **Nombre** | Consultar estadísticas de productos más vendidos |
| **Módulo** | Panel de administración / Analítica |
| **Prioridad** | Baja |
| **Estado** | No Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Muestra un ranking estadístico interactivo con los artículos de mayor demanda comercial en la plataforma para facilitar la toma de decisiones de inventario. Ordena por unidades facturadas (excluye ventas CANCELADAS), con ingresos por producto y stock restante (suma de variantes). Implementado en `adminController.masVendidos` y consumido en `/admin/reportes`.
* **Entradas (query params opcionales):**

| Parámetro | Tipo | Default | Descripción |
| :--- | :--- | :--- | :--- |
| `desde` / `hasta` | `YYYY-MM-DD` | últimos 30 días | Rango de fechas |
| `limite` | Entero | 10 (máx. 50) | Cantidad de productos del ranking |

* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Éxito | 200 | `[{ID, NOMBRE, IMAGEN, unidades, ingresos, stock}]` ordenado por unidades DESC |
| Sin sesión | 401 | Mensaje JSON de sesión inactiva |
| No admin | 403 | `{ ok: false, msg: "No autorizado" }` |
| Error | 500 | `{ ok: false, msg: "Error al obtener los productos más vendidos" }` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/admin/analytics/mas-vendidos`| Admin (`esAdmin`) | Devuelve el ranking de productos más vendidos |
