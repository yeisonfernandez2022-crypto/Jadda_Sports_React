### RF-021 — Generar una factura o comprobante digital
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-021 |
| **Nombre** | Generar una factura o comprobante digital |
| **Módulo** | Pedidos / Facturación |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Compila de manera dinámica un documento en formato PDF descargable que actúa como soporte legal de la transacción comercial efectuada.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `order_id` | Entero (Path) | Sí | ID de una orden con estado verificado `paid` o superior |

* **Proceso:**
    1. El usuario presiona el enlace para bajar el comprobante de su compra.
    2. El backend valida mediante el token JWT la propiedad del pedido.
    3. Extrae la información de la base de datos, compila la estructura y retorna el documento PDF binario adjuntando la cabecera HTTP `content-type: application/pdf`.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Generación exitosa | 200 | Flujo de datos binarios (Stream) del documento PDF |
| Acceso no autorizado | 401 | Mensaje de error: `"You do not have permission to access this invoice"` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/v1/orders/{order_id}/invoice`| Sí | Transmite el archivo PDF de la factura digital del pedido |
