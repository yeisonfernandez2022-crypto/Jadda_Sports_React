### RF-021 — Generar una factura o comprobante digital
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-021 |
| **Nombre** | Generar una factura o comprobante digital |
| **Módulo** | Pedidos / Facturación |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Compila de manera dinámica un documento en formato PDF descargable que actúa como soporte legal de la transacción comercial efectuada. El PDF se genera con `pdfkit` en el backend (`utils/facturaPdf.js`) y también se adjunta al correo de confirmación del checkout.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `id` | Entero (Path) | Sí | ID de una venta existente (en `GET /api/compras/:id/factura` se valida además la propiedad: `ID_CLIENTE = sesión`) |

* **Proceso:**
    1. El usuario presiona "Descargar factura PDF" en Mis Compras (o el admin en Órdenes), lo que abre `GET /api/compras/:id/factura` (o `GET /api/admin/compras/:id/factura`).
    2. El backend valida mediante la sesión de Passport la propiedad del pedido.
    3. Extrae venta + cliente + detalle (DETALLE_VENTAS/PRODUCTOS) + envío de la base de datos, compila el PDF con `utils/facturaPdf.js` (encabezado JADDA SPORTS, datos del cliente, tabla de productos, descuento, envío y total) y retorna el documento binario con `content-type: application/pdf` y `Content-Disposition: attachment`.
    4. En el checkout, el mismo PDF se adjunta al correo de confirmación ("🧾 Factura #id") generado con Nodemailer.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Generación exitosa | 200 | Archivo PDF binario (attachment `factura-<id>.pdf`) |
| No autenticado | 401 | Mensaje JSON de sesión inactiva |
| Compra inexistente / ajena | 404 | `{ ok: false, msg: "Compra no encontrada" }` |
| Error de generación | 500 | `{ ok: false, msg: "Error al generar la factura" }` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/compras/:id/factura` | Sesión (cliente dueño del pedido) | Transmite el archivo PDF de la factura digital del pedido |
| GET | `/api/admin/compras/:id/factura` | Admin (`esAdmin`) | Ídem para cualquier pedido desde el panel administrativo |
