### RF-030 — Visualizar todos los pedidos realizados
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-030 |
| **Nombre** | Visualizar todos los pedidos realizados |
| **Módulo** | Panel de administración / Pedidos |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Ofrece al equipo de operaciones un listado unificado con todas las órdenes de compra del sistema (panel `AdminOrdenes`), con detalle expandible por pedido (productos con variante, dirección, pago, estado de venta y de envío). Implementado con los endpoints reales del sistema.
* **Entradas:** Ninguna. Usuario administrador autenticado (sesión + `esAdmin`).
* **Proceso:**
    1. El administrador abre `/admin/ordenes` (tab "Órdenes" del sidebar).
    2. El frontend consulta `GET /api/admin/compras`.
    3. El backend devuelve cada venta con sus productos (JOIN a `PRODUCTO_VARIANTES` para color/atributo), datos de envío (`ENVIOS`), método de pago y agregados `TOTAL_ARTICULOS`/`TOTAL_UNIDADES`.
    4. El panel muestra KPIs (total, pendientes, en camino, entregadas, canceladas), búsqueda (#/cliente/correo), filtros por estado y fecha, y un detalle expandible por pedido.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Listado correcto | 200 | Array de compras con productos, dirección, pago, `ESTADO`/`ESTADO_ENVIO`, `TOTAL_ARTICULOS`, `TOTAL_UNIDADES` |
| Sin sesión | 401 | Mensaje JSON de sesión inactiva |
| No admin | 403 | `{ ok: false, msg: "No autorizado" }` |
| Error | 500 | `{ ok: false, msg: "Error al obtener compras" }` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/admin/compras` | Sí (Admin) | Lista todos los pedidos del sistema con detalle completo |
| PUT | `/api/admin/compras/:id` | Sí (Admin) | Actualiza el estado de la venta (`VENTAS.ESTADO`, ver RF-031) |
| PUT | `/api/admin/compras/:id/envio` | Sí (Admin) | Actualiza el estado del envío (`ENVIOS.ESTADO_ENVIO`, ver RF-031) |
