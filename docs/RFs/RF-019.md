### RF-019 — Mostrar un resumen final del pedido antes de la confirmación
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-019 |
| **Nombre** | Mostrar un resumen final del pedido antes de la confirmación |
| **Módulo** | Checkout / Pedidos |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Expone en pantalla un bloque inmutable consolidando líneas de compra, envío asignado y totales finales para validación expresa del cliente antes de procesar el pago.
* **Entradas:** Ninguna por parámetro de entrada. Recupera los datos de las fases previas del checkout.
* **Proceso:**
    1. El frontend solicita el estado de cierre de la orden en borrador.
    2. El backend evalúa la persistencia de stock de los ítems en el carrito por última vez y entrega el conjunto consolidado de la orden.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Consolidación lista | 200 | JSON estructurado con todos los datos y cargos fijos del pre-pedido |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/v1/checkout/review` | Sí | Devuelve el balance de datos consolidado previo a la facturación |
