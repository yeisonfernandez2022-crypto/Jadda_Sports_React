### RF-019 — Mostrar un resumen final del pedido antes de la confirmación
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-019 |
| **Nombre** | Mostrar un resumen final del pedido antes de la confirmación |
| **Módulo** | Checkout / Pedidos |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Muestra al cliente un resumen completo del pedido (productos, cantidades, subtotales, dirección de envío, método de pago) antes de confirmar la compra.
* **Entradas:** Ninguna. Consume los datos del carrito desde el frontend.
* **Proceso:**
    1. El frontend renderiza la página `/resumencompra` con todos los datos del carrito.
    2. El usuario puede ver cada producto, su variante, cantidad y precio.
    3. Se aplican cupones de descuento si existen.
    4. El usuario ingresa dirección de envío y selecciona método de pago.
    5. Al confirmar, se envía todo al backend mediante `POST /api/checkout`.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Resumen mostrado | 200 | Renderizado completo en el frontend |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| — | `/resumencompra` (frontend) | Sí | Página de resumen de compra antes del pago |
