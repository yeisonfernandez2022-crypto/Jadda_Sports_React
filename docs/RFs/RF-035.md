### RF-035 — Notificar al cliente cuando un producto vuelva a estar disponible
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-035 |
| **Nombre** | Notificar al cliente cuando un producto vuelva a estar disponible |
| **Módulo** | Fidelización / Alertas |
| **Prioridad** | Baja |
| **Estado** | No Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los usuarios suscribirse a una lista de espera para un artículo variante agotado, enviando un correo automático cuando se registre una entrada en el inventario.
* **Proceso:**
    1. El usuario elige color y atributo de un producto agotado y presiona "Avísame cuando vuelva a estar disponible" (requiere sesión).
    2. El backend registra la suscripción en la tabla `AVISOS_STOCK` (única por usuario + variante, `INSERT IGNORE`).
    3. Cuando el administrador sube el stock de la variante de 0 a > 0 (`PUT /api/productos/:id` con variantes, `PUT /api/productos/variantes/:id` o `POST /api/productos/:id/variantes`), el backend envía email a cada suscriptor y crea una notificación in-app (`NOTIFICACIONES`), marcando el aviso como enviado (`ENVIADO = 1`).
* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/productos/variantes/:id/suscribir` | Sí | Suscribe al usuario a alertas de reposición de stock |
| GET | `/api/productos/variantes/:id/suscripcion` | Sí | Consulta si el usuario ya está suscrito |
| DELETE | `/api/productos/variantes/:id/suscribir` | Sí | Cancela la suscripción del usuario |
