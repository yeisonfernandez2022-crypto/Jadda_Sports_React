### RF-048 — Enviar mensaje de contacto al soporte
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-048 |
| **Nombre** | Formulario de contacto |
| **Módulo** | Soporte técnico |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Permite enviar consultas o sugerencias desde el formulario de la página Contacto. El mensaje se transmite por correo al equipo (Nodemailer) y responde en español.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `nombre` | Texto (Body) | Sí | Nombre del remitente |
| `email` | Texto (Body) | Sí | Formato de correo válido |
| `mensaje`/`asunto` | Texto (Body) | Sí | Contenido del mensaje |

* **Proceso:**
    1. El usuario llena el formulario en `/contacto`.
    2. `POST /api/contacto` (con rate limit 5/15 min por IP) envía el correo vía `config/mailer.js`.
    3. Si el correo falla, devuelve error 500 sin detalle técnico.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Mensaje enviado | 200 | `{ message: "..." }` |
| Too many requests | 429 | Mensaje de límite |
| Error SMTP | 500 | `{ message: "Error al enviar el mensaje. Intenta de nuevo." }` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/contacto` | No | Envía el mensaje de contacto por correo |
| POST | `/api/pqr` | Sí | PQR ligada al usuario (ver RF-039) |
