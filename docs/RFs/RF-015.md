### RF-015 — Calcular y mostrar el total de la compra
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-015 |
| **Nombre** | Calcular y mostrar el total de la compra |
| **Módulo** | Carrito de compras |
| **Prioridad** | Alta |
| **Estado** | Ni implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Computa en cada cambio del carrito las variables monetarias desglosando el subtotal neto y el total final.
* **Entradas:** Ninguna entrada por parámetro de cuerpo. Consume los ítems activos en el carrito.
* **Proceso:**
    1. El sistema ejecuta una sumatoria del precio unitario multiplicado por la cantidad de unidades para cada ítem: $Subtotal = \sum (Precio \times Cantidad)$.
    2. Si aplica un cupón de descuento, se resta el porcentaje correspondiente.
    3. El envío es gratuito para pedidos sobre cierto umbral.
    4. Se muestra el importe final en el frontend.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Cálculo finalizado | 200 | Cálculo realizado del lado del cliente en `CartContext` y `ResumenCompra` |
