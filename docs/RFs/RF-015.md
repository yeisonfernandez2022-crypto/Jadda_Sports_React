### RF-015 — Calcular y mostrar el total de la compra
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-015 |
| **Nombre** | Calcular y mostrar el total de la compra |
| **Módulo** | Carrito de compras |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Computa en cada cambio del carrito las variables monetarias desglosando el subtotal neto, la tasa impositiva por ley (IVA 19%) y los costes logísticos de despacho.
* **Entradas:** Ninguna entrada por parámetro de cuerpo. Consume los ítems activos en la sesión del carrito.
* **Proceso:**
    1. El sistema ejecuta una sumatoria del costo unitario multiplicado por la cantidad de unidades para cada ítem: $Subtotal = \sum (Precio \times Cantidad)$.
    2. Aplica la constante impositiva ($Subtotal \times 0.19$).
    3. Suma los valores de logística correspondientes y computa el importe final.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Cálculo finalizado | 200 | JSON: `{"subtotal": 100.0, "tax": 19.0, "shipping": 5.0, "total": 124.0}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/v1/cart/summary` | Opcional | Entrega el balance e importes financieros detallados del carrito |
