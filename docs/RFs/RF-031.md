### RF-031 — Cambiar el estado de los pedidos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-031 |
| **Nombre** | Cambiar el estado de los pedidos |
| **Módulo** | Panel de administración / Pedidos |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los operadores modificar de manera manual el estado logístico de un pedido para avanzar en el proceso de entrega de la compra.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `status` | Texto | Sí | Valores válidos (`"paid"`, `"shipped"`, `"delivered"`) |
| `tracking_number` | Texto | No | Requerido de forma obligatoria al transicionar al estado `"shipped"` |

* **Proceso:**
    1. El operador updates el estado de un pedido en el panel de control.
    2. El backend valida el rol de administrador, aplica el cambio en la tabla `orders` y, si pasa a `shipped`, exige guardar los datos de seguimiento logístico para notificar al cliente.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Estado modificado | 200 | Confirmación con el nuevo estado del pedido: `{"order_id": 5, "status": "shipped"}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| PATCH | `/api/admin/pedidos/:id/estado`| Sí (Admin) | Actualiza el estado del pedido |
