### RF-026 — Calificar su experiencia de compra
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-026 |
| **Nombre** | Calificar su experiencia de compra |
| **Módulo** | Feedback |
| **Prioridad** | Baja |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los clientes enviar una valoración en estrellas (1 a 5) y comentarios escritos sobre los productos comprados una vez que el pedido haya sido entregado.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `product_id` | Entero (Body) | Sí | Debe coincidir con un producto comprado |
| `rating_stars` | Entero (Body) | Sí | Valor numérico entero acotado del 1 al 5 |
| `comment` | Texto (Body) | No | Opcional, longitud máxima de 500 caracteres |

* **Proceso:**
    1. El usuario rellena la reseña desde su pedido entregado.
    2. El backend comprueba que el usuario posea una orden en estado `delivered` que contenga el `product_id`.
    3. Al validarse, escribe el registro en la tabla `reviews` y actualiza el promedio de puntuación del producto.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Reseña almacenada | 201 | Mensaje informativo: `"Review submitted successfully"` |
| Control infringido | 400 | Mensaje de error: `"You can only review products purchased and delivered"` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/v1/products/{id}/reviews`| Sí | Guarda la calificación verificada del comprador en la base de datos |

* **Reglas de negocio:**
    * **RN-011:** El sistema restringe la creación de reseñas exclusivamente a usuarios que hayan comprado el artículo y cuya orden figure en estado entregado (`delivered`).
