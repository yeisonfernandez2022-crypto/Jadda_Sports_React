### RF-026 — Calificar su experiencia de compra
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-026 |
| **Nombre** | Calificar su experiencia de compra |
| **Módulo** | Feedback |
| **Prioridad** | Baja |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los clientes enviar una valoración en estrellas (1 a 5) y comentarios escritos sobre los productos comprados.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `product_id` | Entero (Body) | Sí | Debe coincidir con un producto comprado |
| `calificacion` | Entero (Body) | Sí | Valor numérico entero del 1 al 5 |
| `comentario` | Texto (Body) | No | Opcional, texto libre |

* **Proceso:**
    1. El usuario puede dejar una reseña desde la página del producto o desde la pantalla post-compra.
    2. El backend escribe el registro en la tabla `RESENAS` con el ID del usuario autenticado.
    3. La reseña incluye calificación y comentario opcional.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Reseña almacenada | 201 | Mensaje: `"Reseña agregada correctamente"` |
| Error de autenticación | 401 | Mensaje de error |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/productos/:id/resenas` | Sí | Guarda la calificación y comentario del comprador |
