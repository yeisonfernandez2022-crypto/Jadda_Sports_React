### RF-013 — Mostrar las opiniones y valoraciones de otros compradores
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-013 |
| **Nombre** | Mostrar las opiniones y valoraciones de otros compradores |
| **Módulo** | Catálogo de productos / Feedback |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los clientes revisar las experiencias y puntuaciones otorgadas por otros usuarios para cada artículo deportivo específico.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `id` | Entero (Path) | Sí | ID del producto a consultar opiniones |

* **Proceso:**
    1. El sistema recupera los registros de la tabla `RESENAS` enlazados al ID del producto.
    2. Ejecuta operaciones aritméticas de agregación para obtener la media matemática de la puntuación en estrellas e integra los textos de los testimonios de los compradores.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Reviews obtenidas | 200 | JSON: `{"average_rating": 4.5, "total_reviews": 12, "reviews": [...]}` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/productos/:id/resenas` | No | Recupera todas las reseñas de un producto |
| POST | `/api/productos/:id/resenas` | Sí | Agrega una reseña (calificación + comentario) |
