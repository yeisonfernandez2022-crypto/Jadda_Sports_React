### RF-046 — Subir imágenes de productos desde el panel administrador
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-046 |
| **Nombre** | Subida de imágenes (admin) |
| **Módulo** | Panel de administración / Catálogo |
| **Prioridad** | Media |
| **Estado** | Implementado |
| **Fecha** | Agosto 2026 |

* **Descripción:** Permite al administrador subir imágenes de productos desde su computador (multi-archivo, base64) o pegar una URL, desde el modal de agregar producto o en `EditarProductoAdmin` (Sidebar). Las imágenes se guardan en `backend/uploads/subidas/` (bind-mount `frontend/public/images/productos`) y el `crearProducto`/`actualizarProducto` las reciben como arreglo `IMAGENES` (URLs con ORDEN secuencial 1..N).
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `imagenes` | Array (Body) | Condicional | Cada imagen: `{ base64 o url }`, ≤ 25 MB por petición |
| `IMAGENES` | Array de URLs | No | URLs asignadas al producto con ORDEN secuencial |
| `URL_IMAGEN` | Texto | No | Fallback: imagen individual |

* **Proceso:**
    1. `SubirImagenes.tsx` (usado en `AdminProductos` y `EditarProductoAdmin`) lee archivos (jpg/png/webp/gif), genera previews con botón ✕ o acepta URL pegada.
    2. `POST /api/productos/imagenes` recibe base64 (límite 25mb configurado en la ruta y en `server.js`) y devuelve las URLs `/images/productos/subidas/<ts>-<rand>.<ext>`.
    3. Al guardar el producto, `IMAGENES` se inserta en `PRODUCTO_IMAGENES` con ORDEN 1..n.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Imágenes subidas | 200 | `{ ok, urls: [...] }` |
| Sin archivo/base64 | 400 | Mensaje de error |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/productos/imagenes` | Admin | Sube imágenes base64 al almacenamiento local |
| POST/PUT | `/api/productos` `/api/productos/:id` | Admin | Reciben `IMAGENES` (array de URLs) |

* **Nota defuncionamiento:** funciona SOLO en Docker (bind-mount `./frontend/public/images/productos:/app/uploads`).
