### RF-017 — Ingresar la dirección de envío
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-017 |
| **Nombre** | Ingresar la dirección de envío |
| **Módulo** | Checkout / Pedidos |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite al cliente registrar y seleccionar direcciones de envío para sus pedidos.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `direccion` | Texto | Sí | Mínimo 5 caracteres |
| `ciudad` | Texto | Sí | Ciudad de entrega |
| `departamento` | Texto | Sí | Departamento de entrega |
| `barrio` | Texto | No | Barrio de residencia |
| `telefono_contacto` | Texto | Sí | Número de contacto |
| `codigo_postal` | Texto | No | Código postal |

* **Proceso:**
    1. El cliente rellena los campos de ubicación dentro de la interfaz de pago o desde su perfil.
    2. El backend valida los datos y guarda la dirección en la tabla `DIRECCIONES`.
    3. Durante el checkout, el usuario puede seleccionar una dirección guardada o agregar una nueva.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Dirección guardada | 201 | Datos de la dirección creada |
| Direcciones listadas | 200 | Lista de direcciones del usuario |
| Errores de formato | 400 | Mensaje de error descriptivo |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/direcciones` | Sí | Obtiene las direcciones del usuario |
| POST | `/api/direcciones` | Sí | Crea una nueva dirección |
| PUT | `/api/direcciones/:id` | Sí | Actualiza una dirección existente |
| DELETE | `/api/direcciones/:id` | Sí | Elimina una dirección |
