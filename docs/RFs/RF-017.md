### RF-017 — Ingresar la dirección de envío
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-017 |
| **Nombre** | Ingresar la dirección de envío |
| **Módulo** | Checkout / Pedidos |
| **Prioridad** | Alta |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Registra las coordenadas y datos geográficos de entrega en los que el cliente desea recibir el despacho de su compra física.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `address_line` | Texto | Sí | Nomenclatura exacta, mínimo 5 caracteres |
| `city` | Texto | Sí | Ciudad destino contemplada dentro del rango de cobertura |
| `postal_code` | Texto | Sí | Formato de código postal nacional válido |

* **Proceso:**
    1. El cliente rellena los campos de ubicación dentro de la interfaz de pago.
    2. El backend valida los datos e indexa temporalmente la dirección de envío elegida a la orden en borrador (`pending_checkout`).
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Ubicación enlazada | 200 | Mensaje informativo: `"Shipping address successfully set"` |
| Errores de formato | 422 | Listado detallado indicando fallos sintácticos en los campos |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| POST | `/api/v1/checkout/shipping-address`| Sí | Vincula la localización geográfica al pedido en curso |
