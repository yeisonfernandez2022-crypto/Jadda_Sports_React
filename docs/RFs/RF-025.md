### RF-025 — Enviar notificaciones del estado y envío del pedido mediante correo electrónico
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-025 |
| **Nombre** | Enviar notificaciones del estado y envío del pedido mediante correo electrónico |
| **Módulo** | Notificaciones |
| **Prioridad** | Media |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Envía correos informativos automáticos al cliente cada vez que los operadores modifiquen el estado logístico de entrega de su paquete.
* **Entradas:** Evento interno del sistema disparado por cambios en las entidades de órdenes.
* **Proceso:**
    1. Cuando una orden cambia de estado (ej: pasa a `shipped`), se dispara un trigger en el backend.
    2. El microservicio de notificaciones recopila los datos, monta el correo con la URL de la transportadora y envía el mensaje de forma asíncrona.
* **Salidas:** Operación y ejecución interna del servidor de correos.
