### RF-032 — Generar reportes de ventas
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-032 |
| **Nombre** | Generar reportes de ventas |
| **Módulo** | Panel de administración / Analítica |
| **Prioridad** | Media |
| **Estado** | No implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Consolida información de ventas basándose en un rango de fechas seleccionado, calculando indicadores clave como ingresos totales, cantidad de órdenes, ticket promedio y unidades vendidas (excluye ventas CANCELADAS). Además devuelve la serie diaria de ingresos/órdenes para el gráfico. Implementado en `adminController.reporteVentas` y consumido en la página `/admin/reportes`.
* **Entradas (query params opcionales):**

| Parámetro | Tipo | Default | Descripción |
| :--- | :--- | :--- | :--- |
| `desde` | `YYYY-MM-DD` | hace 30 días | Inicio del rango |
| `hasta` | `YYYY-MM-DD` | hoy | Fin del rango (inclusive) |

* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Éxito | 200 | `{desde, hasta, totalOrdenes, totalIngresos, ticketPromedio, totalUnidades, serie[]}` |
| Sin sesión | 401 | Mensaje JSON de sesión inactiva |
| No admin | 403 | `{ ok: false, msg: "No autorizado" }` |
| Error | 500 | `{ ok: false, msg: "Error al generar el reporte de ventas" }` |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/admin/reportes/ventas` | Admin (`esAdmin`) | Devuelve las métricas financieras de ventas por rango de fechas |
