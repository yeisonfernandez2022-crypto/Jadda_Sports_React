### RF-020 — Enviar la confirmación del pedido al correo electrónico del cliente
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-020 |
| **Nombre** | Enviar la confirmación del pedido al correo electrónico del cliente |
| **Módulo** | Pedidos / Notificaciones |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Dispara automáticamente el envío de un correo electrónico con los detalles del comprobante de compra y confirmación de la transacción cuando la pasarela certifique el cobro.
* **Entradas:** `order_id` (Generado internamente por el sistema tras confirmación de pago del webhook).
* **Proceso:**
    1. Al confirmarse la compra, `checkoutController.procesarCompra` ejecuta la transacción (BEGIN/COMMIT) de venta + detalle + envío.
    2. Se genera la confirmación con Nodemailer al EMAIL del cliente: asunto "🧾 Factura #id", HTML con los detalles del pedido y la factura PDF adjunta.
    3. El envío es síncrono dentro del checkout con try/catch: si el correo falla, la compra no se rompe.
* **Salidas:** Email HTML con adjunto PDF (flujo interno, sin respuesta HTTP extra al usuario).
* **Reglas de negocio:**
    * **RN-009:** El correo de confirmación se envía en el mismo flujo de checkout (síncrono, sin colas).
