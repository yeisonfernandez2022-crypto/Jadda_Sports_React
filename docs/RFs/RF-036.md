### RF-036 — Crear y gestionar una lista de deseos
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-036 |
| **Nombre** | Crear y gestionar una lista de deseos |
| **Módulo** | Interacción de usuarios |
| **Prioridad** | Baja |
| **Estado** | Por implementar |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los clientes autenticados guardar productos de su interés en una lista personal para poder localizarlos y comprarlos fácilmente en el futuro.
* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/v1/wishlist` | Sí | Obtiene todos los artículos guardados en la lista de deseos |
| POST | `/api/v1/wishlist/{product_id}`| Sí | Añade un producto del catálogo dentro de la lista de deseos |
| DELETE| `/api/v1/wishlist/{product_id}`| Sí | Elimina un artículo de la lista de deseos del usuario |
