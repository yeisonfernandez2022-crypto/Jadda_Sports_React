### RF-007 — Filtrar productos por categoría y marca
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-007 |
| **Nombre** | Filtrar productos por categoría y marca |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los usuarios acotar la visualización del catálogo deportivo interactuando con parámetros específicos para restringir la búsqueda a ciertas categorías o marcas asociadas.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `category_id` | Entero (Query) | No | Debe coincidir con una PK de categoría válida |
| `brand_id` | Entero (Query) | No | Debe coincidir con una PK de marca válida |

* **Proceso:**
    1. El usuario marca filtros en la barra de navegación del frontend.
    2. Los parámetros se adjuntan a la URL como argumentos query.
    3. El backend concatena condicionales dinámicos a la consulta ORM basándose en los ID proporcionados.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Filtro exitoso | 200 | Lista de productos filtrados que cumplen con los criterios |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/v1/products` | No | Permite el paso opcional de filtros `category_id` y `brand_id` |

* **Reglas de negocio:**
    * **RN-006:** Los criterios de filtrado operan combinados bajo la lógica distributiva AND; los ítems resultantes de la búsqueda deben cumplir obligatoriamente todas las condiciones concurrentes.
