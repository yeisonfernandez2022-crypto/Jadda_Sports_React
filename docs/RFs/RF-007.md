### RF-007 — Filtrar productos por categoría y marca
* **Identificación:**

| Campo | Valor |
| :--- | :--- |
| **ID** | RF-007 |
| **Nombre** | Filtrar productos por categoría y marca |
| **Módulo** | Catálogo de productos |
| **Prioridad** | Alta |
| **Estado** | Implementado |
| **Fecha** | Mayo 2026 |

* **Descripción:** Permite a los usuarios acotar la visualización del catálogo deportivo interactuando con parámetros específicos para restringir la búsqueda a ciertas categorías o marcas asociadas.
* **Entradas:**

| Campo | Tipo | Obligatorio | Validaciones |
| :--- | :--- | :--- | :--- |
| `categoria` | Entero (Query) | No | Debe coincidir con un ID de categoría válido |
| `marca` | Texto (Query) | No | Debe coincidir con una marca existente |

* **Proceso:**
    1. El usuario selecciona filtros en la página de catálogo.
    2. Los parámetros se adjuntan a la URL como query strings.
    3. El backend agrega condiciones WHERE a la consulta SQL basándose en los parámetros proporcionados.
* **Salidas:**

| Escenario | Código HTTP | Respuesta |
| :--- | :--- | :--- |
| Filtro exitoso | 200 | Lista de productos filtrados |

* **Endpoints asociados:**

| Método | Ruta | Auth requerida | Descripción |
| :--- | :--- | :--- | :--- |
| GET | `/api/productos` | No | Permite el paso opcional de filtros `categoria` y `marca` |
